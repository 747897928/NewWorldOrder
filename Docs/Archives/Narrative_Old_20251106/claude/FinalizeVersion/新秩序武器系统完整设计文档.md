# 文档2：《新秩序》武器系统完整设计文档

------

## 1. CSV结构定义

### CSV 1: WeaponStats.csv（主表）

```csv
WeaponID,WeaponName,WeaponType,BaseDamage,MagazineSize,FireRateRPM,BaseSpreadAngle,SpreadPerShot,MaxSpreadAngle,SpreadRecovery,BulletsPerShot,CritMultiplier,FalloffCurveID,ReloadTime,ReloadType,WeaponTier
```

字段说明（每个字段的含义）：

| 字段名          | 类型   | 说明                   | 示例                          |
| --------------- | ------ | ---------------------- | ----------------------------- |
| WeaponID        | String | 唯一标识符             | WPN_AK47                      |
| WeaponName      | String | 武器显示名称           | AK-47                         |
| WeaponType      | String | 武器类型               | AR/SMG/SG/SR/LMG/Pistol/RL/GL |
| BaseDamage      | Float  | 基础伤害（每发子弹）   | 35.0                          |
| MagazineSize    | Int32  | 弹夹容量（发）         | 30                            |
| FireRateRPM     | Float  | 射速（发/分钟）        | 600.0                         |
| BaseSpreadAngle | Float  | 基础扩散角度（度）     | 1.5                           |
| SpreadPerShot   | Float  | 每发增加扩散角度（度） | 0.8                           |
| MaxSpreadAngle  | Float  | 最大扩散角度（度）     | 6.0                           |
| SpreadRecovery  | Float  | 扩散恢复速度（度/秒）  | 3.0                           |
| BulletsPerShot  | Int32  | 单次射击子弹数         | 1（霰弹枪=8）                 |
| CritMultiplier  | Float  | 弱点伤害倍率           | 2.0                           |
| FalloffCurveID  | String | 距离衰减曲线ID         | Curve_MidRange                |
| ReloadTime      | Float  | 换弹时间（秒）         | 2.2                           |
| ReloadType      | String | 换弹类型               | Magazine/Single               |
| WeaponTier      | Int32  | 武器品质               | 1-5                           |

------

### CSV 2: WeaponFalloffCurves.csv（衰减曲线表）

```csv
CurveID,CurveName,Point1_Distance,Point1_Mult,Point2_Distance,Point2_Mult,Point3_Distance,Point3_Mult,Point4_Distance,Point4_Mult
```

字段说明：

- Distance单位：厘米（cm），100cm=1米
- Mult：伤害倍率（1.0=100%伤害，0.5=50%伤害）
- 4个关键点定义曲线，UE5运行时自动插值

------

### CSV 3: EnemyStatsPerChapter.csv（敌人血量配置）

```csv
ChapterID,EnemyType,EnemyTier,BaseHP,Diff_Normal,Diff_Hard,Diff_Master,Diff_Nightmare
```

字段说明：

- EnemyTier：敌人分级（Common普通/Special特殊/Elite精英/Boss首领）
- BaseHP：基础血量
- Diff_X：难度倍率（普通1.0，困难1.3，大师1.6，噩梦2.0）

------

### CSV 4: AmmoConfig.csv（弹药配置）

```csv
WeaponType,MaxAmmo,PickupCommon,PickupSpecial,PickupElite
```

字段说明：

- MaxAmmo：最大携带弹药（不含弹夹内）
- PickupX：拾取弹药数量（按敌人类型）

## 2. 武器衰减曲线预设

### Curve_CloseRange（近距离 - 霰弹枪）

```csv
CurveID,CurveName,Point1_Distance,Point1_Mult,Point2_Distance,Point2_Mult,Point3_Distance,Point3_Mult,Point4_Distance,Point4_Mult
Curve_CloseRange,近距离衰减,0,1.0,500,1.0,1000,0.5,2000,0.1
```

曲线解读：

- 0-5米：100%伤害
- 5-10米：快速衰减到50%伤害
- 10-20米：极速衰减到10%伤害
- 设计意图：强制近战，超过10米基本无效

------

### Curve_MidRange（中距离 - 步枪/冲锋枪）

```csv
CurveID,CurveName,Point1_Distance,Point1_Mult,Point2_Distance,Point2_Mult,Point3_Distance,Point3_Mult,Point4_Distance,Point4_Mult
Curve_MidRange,中距离衰减,0,1.0,2000,1.0,5000,0.7,8000,0.4
```

曲线解读：

- 0-20米：100%伤害
- 20-50米：缓慢衰减到70%伤害
- 50-80米：继续衰减到40%伤害
- 设计意图：中近距主战场，远距仍有威胁

------

### Curve_LongRange（远距离 - 狙击枪）

```csv
CurveID,CurveName,Point1_Distance,Point1_Mult,Point2_Distance,Point2_Mult,Point3_Distance,Point3_Mult,Point4_Distance,Point4_Mult

曲线解读：

- 0-30米：100%伤害
- 30-60米：保持90%伤害
- 60-100米：衰减到75%伤害
- 设计意图：全距离有效，远距优势明显

------

### Curve_NoFalloff（无衰减 - 爆炸武器）

## 5. 与技能系统协同验证

### 5.1 武器80%，技能20%的输出比例

测试场景：击杀游荡者150HP（力量30玩家）

纯枪械（AK-47）：

- 伤害：50.75/发
- 击杀：3发=152.25伤害
- TTK：0.2秒
- 占比：100%输出

枪械+战术标记（+25%）：

- 伤害：50.75×1.25=63.44/发
- 击杀：3发=190.32伤害
- TTK：0.2秒（仍需3发）
- 提升：标记让3发更稳定，容错高
- 重要：标记不触发额外回血

枪械+破甲射击（弱点+30%）：

- 基础弱点：×2.0
- 破甲后：×2.3（基础×2.0+30%加成）
- 弱点伤害：50.75×2.3=116.73/发
- 击杀：2发弱点=233.46伤害
- TTK：0.1秒
- 技能提供质变，但需精准打弱点

枪械+战术超载（射速+30%，无限弹）：

- 伤害不变：50.75/发
- 射速：600→780RPM（13发/秒）
- DPS：350→455（+30%）
- 持续12秒（最多），总输出：455×12=5460伤害
- 等效击杀：5460/150=36只游荡者
- 实际考虑换弹，纯枪械约25只

  {
      // 获取距离衰减倍率
      float FalloffMult = DistanceFalloff.GetRichCurveConst()->Eval(Distance);
      
      // 计算最终伤害
      float FinalDamage = BaseDamage * FalloffMult;
      
      return FinalDamage;
  }
  
  // 弱点伤害计算
  float ARangedWeaponInstance::CalculateCriticalDamage(float BaseDamageValue) const
  {
      return BaseDamageValue * CritMultiplier;
  }
  ```

  ## 10. 总结

  ### 核心设计验证

  TTK区间健康：0.3-0.7秒，所有主武器符合预期 武器80%，技能20%：数值验证通过 成长不通胀：章节血量递增维持难度 回血平衡：608.4HP回血，预期受伤400HP，净+208.4HP（+80%） 弹药经济：162发掉落，149发消耗，刚好够用

  ### 武器族群差异化

  AR：平衡全能，中距主力 SMG：高射速机动，近战优势 SG：极端近战，5米内爆发 SR：精准狙杀，身体秒杀普通敌人 LMG：弹幕压制，防守核心 爆炸武器：战术工具，稀缺资源

  ### 关键设计原则

  数值明确性：

  - 每发伤害35（不是DPS35）
  - 击杀回血6%最大生命值（不是按伤害百分比）
  - 换弹时间-30%（2.2秒→1.54秒）

  防滥用机制：

  - 标记可用于任何敌人（战术通用）
  - 回血仅精英/特殊触发（防刷小怪）
  - 弹药掉落率精英60%（防过量）

  技能哲学：

  - 技能辅助枪械，不替代枪械
  - 主要伤害来源仍是武器（80%）
  - 技能是倍增器，缩短TTK
