## 1. 核心游戏框架

### 1.1 类型与定位

- 第三人称合作生存射击（TPS Co-op，丧尸题材）。
- 双主角协作：陈浩宇（输出/破坏）、沈芸皖（治疗/支援/侦察）。
- 玩法三柱：战术射击 + 资源管理 + 碎片化叙事。
- 模式：
  - 单人：一人操控，AI 接管另一主角；压力与数量做**PPS 软自适应**（详见 §14）。
  - 本地竖直分屏：2 人同屏。
  - 在线合作：Steam P2P Listen Server（2 人）。

### 1.2 目标体验

- **“丧尸无处不在”**的生存紧张感；合作切换与技能互补的战术满足；推进式章节副本便利复盘与重玩。

### 1.3 章节规模

- 10–15 章线性副本；单章 30–60 分钟；全程 ≥ 8 小时；每章 2–4 个主场景、5–8 场战斗、3–5 个关键对话/选择。

## 2. 创作红线与通用口径

### 2.1 叙事红线

- 反派**有脑子**、行为**自洽**；没有“纯善/纯恶”。
- **钱从哪来**的经济逻辑必须成立。
- **丧尸战斗≥50%**；人类冲突仅作环境张力与任务动机。
- 碎片化线索，不搞说教；玩家做选择、承担代价。

### 2.2 战斗与数值口径（统一）

- 移除**随机暴击**；统一为**弱点命中**才享受**弱点伤害倍率**（见 §17）。
- **通用 CDR**指“全技能冷却缩减”的统一口径；除非特别声明，**不作用于翻滚与大招**。
- 控制抗性：
  - 普通与特殊：可被打断 + **禁技 2s（普通）/1s（特殊）**。
  - 精英：**仅打断**。
  - Boss：仅打断（不可硬控）。
- Lv20 质变：解锁**武器改装槽**（见 §17.5）。
- 取消“等级生命/伤害补偿”，改为**仅给属性点**；整体强度用**PPS**调度（见 §14）。

## 11. 关键设计哲学与方法论

- **丧尸 ≥ 50% 战斗时长**的铁律。
- **PPS 软自适应**替代“等级补偿”；以压力曲线与组合机制创造难度，而不是简单血量膨胀。
- **弱点导向**替代随机暴击；**贴脸加成**让近战/霰弹有位阶价值。
- **控制抗性分层**确保高端敌人不被“无脑控”。

## 14. 战斗与数值系统总则（统一口径）

### 14.1 核心公式

```text
DPS = 武器伤害 × 射速 × (1 + 弱点命中率 × (弱点倍率 - 1))
```

- **弱点命中率**仅在命中敌人弱点（如头部、特定发光点）时计入；不存在随机暴击。

### 14.2 PPS（Pressure Per Second）软自适应

- 概念：衡量“压力单位/秒”的在线调度器，依据**同屏数量、特殊敌人权重、地形劣势、弹药占比、玩家体力/血量**等信号调节刷新与组合。
- 目标：
  - **新手：略低压爽玩**；
  - **熟练：持续紧张但可控**；
  - **高手：边缘博弈、犯错必付出代价**。
- 技术规则（简化）：
  - 每 5s 评估压力：`P = 常规数 ×1 + 特殊数 ×2 + 精英数 ×3 + 地形劣势 ×1~3`。
  - 低压（P<5）：加速刷新（5–8 只/波）。
  - 中压（5≤P≤15）：常速。
  - 高压（15<P≤25）：延迟刷新。
  - 极限（P>25）：暂停 30s；若玩家血量<30%或弹药<20%，额外减速。
  - 每 5 分钟**平静期** 60s；关键节奏点触发**尸潮期**短爆发。

### 14.3 等级与成长

- **取消“每级生命/伤害补偿”**；升级只授予**属性点**与**系统解锁**（如 Lv20 改装槽）。
- 难度/章节强度通过**敌人组合/行为策略/地形/补给密度**与**PPS**实现。

### 14.4 控制抗性（再申明）

- 普通/特殊：可被**打断 + 禁技 2s/1s**。
- 精英：仅可**打断**；不可禁足或长控。
- Boss：仅可打断；以“**输出窗口**”替代硬控。

## 15. 敌人谱系与关卡导演（Director-Lite）

### 15.1 敌人类型（样例口径）

**游荡者（Wanderer）**

- 角色：数量/充能/反馈来源。
- Lv1 参考：HP **90**（锚点），伤害 15/s，近战 1.5m。
- 行为：靠近→挥击；AI 简单但数量多。
- 反制：自动火或连发步枪、轻武器；AOE 清群。

**猎手（Hunter）**

- 角色：高速突袭与节奏打断。
- Lv1：HP 150，冲刺扑击伤害 40，CD 3s，10m 视野判定。
- 行为：0.5s 尖叫前摇→直线冲刺→命中击退；被标记后移速 +30%。
- 反制：翻滚规避、震撼手雷打断、地面陷阱。
- 体验：听声辨位+瞬时决策。

**爬行者（Crawler）**

- 角色：低姿态骚扰，强制视角下压。
- Lv1：HP 120，身高 0.8m，5 m/s，抓腿 25/s。
- 行为：贴地/墙爬，被击中翻滚复位。
- 反制：霰弹/爆破/AOE；地面控制。
- 体验：促使武器切换与准星管理。

**吞噬者（Devourer）**（**重制装甲模型**）

- 角色：重装中 Boss，团战核。
- 装甲规则：
  - **正面扇区减伤 60%**（固定阈值+比例），**背部弱点 3×**；
  - **蓄力重击**前摇 2s，5m AOE，击飞+裂纹 DoT；
  - **侧面**减伤 30%。
- Lv1：HP 1500，护甲阈值 30/比例 30%，伤害 80，每 4s。
- 反制：诱饵拉面向、冰控绕背、破甲/穿刺打点；双人配合分工。
- 体验：围绕“面向—背刺—窗口”的战术解谜。

**Boss：腐化泰坦（Corrupted Titan）**

- 三阶段曲线+**输出窗口**事件（冲撞眩晕/倒地 5s/死亡爆发预警 5s）。
- 强调“学招式→等待时机→爆发”，并在阶段切换给出**补给窗口**与**小怪干扰**。

> 其他新异种（尖啸者、觉醒者、尸王）沿旧文设定延展；控制抗性按统一口径。

### 15.2 导演系统（简化）

- 压力值评估与刷新策略见 §14.2。
- **平静期/尸潮期**为宏观呼吸；**战斗块**为微观拼接（走廊压迫 → 开阔拉扯 → 精英穿插 → 资源点补给 → 追击撤离 → Boss）。

## 16. 难度分级与同屏上限

- **普通**：新手/剧情；同屏 ≤8；组合简单；刷新间隔长。
- **困难**：战术要求↑；同屏 ≤15；开始出现“猎手+群”组合。
- **大师**：核心向；同屏 ≤25；精英变种与复杂交叉节奏。
- **噩梦**：硬核；同屏不设硬上限（分批）；全员精英化+Boss 强化；补给下调。

> 难度不是血量×N，而是**行为+数量+组合+地形**。PPS 始终在线。

------

## 17. 武器与 TTK、贴脸加成与弱点规则

### 17.1 TTK 平衡目标

- 不造“最强枪”，而是**场景最优解**：
  - 霰弹：近距贴脸强，群清效率高。
  - 狙击：单点爆弱点，点名精英。
  - AR/SMG：通用、持续火力与手感担当。
  - 榴/火箭：范围爆发与控场（资源稀缺）。

### 17.2 贴脸加成（近战/霰弹）

- **0–3m**：伤害插值至 **1.2×–1.35×**（武器系数+弹型决定上限）；
- **散布与命中壳**：近距散布收敛（SpreadExponent↑），霰弹命中壳半径放宽，提升体感命中率。

### 17.3 弱点与命中辅助

- **弱点倍率**：
  - 常规 1.5×；
  - 特殊 1.75×；
  - 精英 2.0×；
  - 吞噬者背点 3.0×（受面向与装甲判定）。
- **弱点命中辅助**：轻度吸附与抖动抑制仅在弱点区域生效，鼓励“真瞄真打”。

### 17.4 伤害衰减与散布

- 距离衰减使用曲线（近距平、远距滑）；散布积累/恢复参数按武器档分层；**开镜/半握**对散布恢复与后坐施加修正。

### 17.5 Lv20 改装槽（质变位）

- 解锁**1–2 槽**（主槽+副槽）：
  - 主槽：枪管/机件/供弹，改变伤害模型或控制参数（如后坐、换弹、穿透）。
  - 副槽：瞄具/握把/枪托，影响弱点命中辅助、ADS 速度、移动开火惩罚等。
- 改装无随机词条；**定轴可控**，利于平衡与制作量。

## 18. 技能系统（男女主）—CD/充能与控制抗性

### 18.1 统一口径

- **通用 CDR**不影响**翻滚**与**大招**（两者走充能或充能制）。
- 控制效果按 §14.4 抗性执行；任何“持续群控”设计均对精英/Boss **降效或免疫**。

### 18.2 男主关键技能（口径整理）

- **战术标记**：**充能制**（2 次，间隔 15s），持续 8s，目标受伤 +30%。击杀被标记单位为大招提供额外充能。
- **爆破投掷**：18s，5m AOE，300 伤害，2s 延迟。
- **精准打击**：15s，1.5s 窗口内子弹**必定弱点判定**（等效于“必定暴击”口感，但遵守弱点体系），且弱点倍率 +100%（只对真实弱点生效）。
- **震撼手雷**：25s，3m AOE，**打断**+脆弱（受伤 +50% 持续 3s）。
- **破甲射击**：20s，10s 内护甲 -50% + 弱点伤害 +30%。
- **战术翻滚**：**充能制**（3 次，充能 12s），0.4s 无敌。
- **狂怒模式（大招）**：100 点充能，12s，攻速 +80%/伤害 +50%/移速 +40%/受伤 -30%；击杀延长 1s（至多 +8s）。

### 18.3 女主关键技能（口径整理）

- **医疗站**：30s，15s 持续，半径 5m，5%/s。
- **治疗飞镖**：15s，瞬回 30% + HOT 15%/5s；**治疗递减**：10s 内第 2 次 70% 效果。
- **护盾发生器**：35s，8s，吸收至 **25% Max HP**（上限），统一持续。
- **战地复苏**：90s，复活 +50% 血 + 5s 无敌。
- **战术扫描**：25s，15m，15s，标记 + 弱点突显 + 暴伤相关增益。
- **冰霜陷阱**：20s，最多 3 个；触发 5m：游荡 3s/猎手 1.5s/精英免疫；Boss 仅减速/打断。
- **电磁脉冲**：30s，8m，麻痹 2s（对精英 1s），技能刷新类效果对 Boss **不生效**。
- **生命脉冲（大招）**：100 点充能，瞬发 15m：恢复 60% + 伤害 +30% + 20% 护盾，并清除负面。

### 18.4 大招充能对称性

- 男主：击杀与受伤双通道；特殊/精英/Boss 加权。
- 女主：**治疗与“技能使用”**直接充能（单人模式不依赖 AI），友军击杀/受伤辅助。

# 20. 换装系统

技术实现: **Mutable**：程序化换装系统

男女主的服装是分开的，男女主穿了什么衣服通过Mutable的GamePlayTag来判断。服装仅仅是装饰类物品不影响数值。

```c++
UCustomizableObjectInstance* ObjectInstance = HeadCSkeletalComponent->GetCustomizableObjectInstance();

const FGameplayTagContainer& AnimationGameplayTags = ObjectInstance->GetAnimationGameplayTags();
```

GamePlayTag例：

```
Female.Head.HeadAccessories.BobHair

Female.Head.HeadAccessories.BunHair

Female.Body.Shoes.Heels

Female.Body.Pants.Hotpants

Female.Body.Shoes.Sneakers

Female.Body.Shirts.TShirts

Male.Body.Shoes.Sneakers

Male.Body.Pants.JeansMale

Male.Head.HeadAccessories.EdgeCutHair

Male.Body.Shirts.TShirtMale
```



玩家可以在主菜单进入玩家的家园(Hub)，进入后默认会选择男主(除非你退出游戏时存档记录你最后选择的是女主)，你会在家园的某处(比如沙发上)看到另一个主角(如果你当前选择的是男主，你会看到的是女主)，未选中的主角会根据当前状态播放它的待机动画。当你走进另一个主角时，会显示交互按钮(切换陈浩宇/切换沈芸皖)，你只需点击交互键，即可切换对应的主角。

**技术栈**：UE5 + **Mutable**（Runtime），外观**纯装饰**，**绝不影响数值**。

**角色双主角**：陈浩宇（男）/ 沈芸皖（女）**独立衣柜**；用 **GameplayTag** 标识当前装扮与部件。

**单一 ASC（Ability System Component）共用**：切换主角时，**重装技能集/被动**、**刷新属性快照**、**替换 SkeletalMesh/AnimBP/Mutable 服装实例**、**同步 UI 与音色**。

**存档域**：外观、当前主角选择、最后着装在 **Hub 永久存档**；副本内不变更外观。

## 21. 开发规模控制与版本里程碑

- 线性副本与章节化迭代；每章“战斗块→呼吸→精英/事件→撤离/Boss”。
- 长线版本里程碑：
  1. **战斗垫片**（核心射击手感 + 3 敌种 + 1 关卡块）。
  2. **章节灰盒**（PPS 线上 + 导演算子 + 基础掉落/补给）。
  3. **全流程 Alpha**（10 章可过、难度口径一致）。
  4. **平衡 Beta**（TTK/贴脸/弱点与 I/O 数据闭环）。
  5. **内容冻结 RC**（只修 Bug 与平衡微调）。

## 22. 术语表与口径速查

- **PPS**：Pressure Per Second，在线压力评估与刷新调度。
- **弱点倍率**：仅弱点命中时生效的乘区（不等于随机暴击）。
- **通用 CDR**：全技能冷却缩减，**不含**翻滚与大招。
- **禁技**：技能/特殊动作锁定的软控，时间短、可读性强。
- **输出窗口**：Boss/精英在特定事件后的脆弱短窗。
- **贴脸加成**：0–3m 伤害插值，霰弹/近战专属优待。
- **改装槽**：Lv20 解锁的枪械质变位，主/副 2 层。

# 附：系统与内容细化（可直接落地的关键条目）

以下条目为团队落地时的“即插即用”细节，均已按统一口径收敛，避免返工。

## A. 敌人出现时机（20 分钟标准副本样例）

- 开场 0–2′：游荡少量热身（8 只）；拾补给。
- 初接触 2–5′：游荡群 + 首次猎手（2 只）；教反制。
- 复杂战 5–10′：混合三波（游荡/猎手/爬行），走廊地形。
- 精英战 8–12′：吞噬者 ×1（主威胁）+ 持续小怪干扰。
- 撤离战 10–13′：后方追击（游荡 25 + 猎手 6）。
- Boss 12–17′：三阶段 + 切换补给 + 小怪插入。
- 结算 17–20′：回 Hub/剧情。

> 实际刷新由 PPS 与导演算子共同裁决，确保**平均每 7–8s 有击杀**，但不淹没读条/演出。

## B. 敌人数量黄金配比（困难难度样例）

- 游荡 70% / 猎手 15% / 爬行 10% / 吞噬 5%（Boss 之外）。
- 20′ 目标总数 ~160；同屏上限按难度条款执行。

## C. 同屏数量（技术+设计）

- 普通 ≤8；困难 ≤15；大师 ≤25；噩梦分批不封顶。
- UE5 侧约束：寻路批次/碰撞批次/可见性批次限制，与 AI Tick 降采样策略配套。

## D. 枪械字段（实现口径）

- `BaseDamage`、`MagazineSize`、`AmmoPerShot`、`FireRateRPM`、`MaxRange`
- Spread：`BaseSpreadAngle`/`SpreadAnglePerShot`/`MaxSpreadAngle`/`SpreadRecoveryRate`/`SpreadExponent`
- `BulletTraceSweepRadius`、`BulletsPerCartridge`
- `DistanceFalloff`（曲线）
- `WeakpointMultiplier`（按武器或全局读取敌种倍率表）

## E. 行为控制与硬直/打断

- **打断**触发来源：震撼手雷/重武器爆震/Boss 特定事件/猎手扑空/吞噬者蓄力中被重击。
- **短硬直**（摄像机与动作微停）提升手感但**不赋予控制**；精英/Boss 仅接受该层级。

## F. 治疗与护盾递减

- 10s 内第 2 次治疗 → 70% 效果；第 3 次 → 40%。
- 护盾上限 25% Max HP，统一 10s 持续；新增护盾刷新为“替换而非叠加”。

## G. 翻滚与资源管理

- **翻滚**：0.4s 无敌，充能制 3 次/12s；不可被 CDR 影响。
- **投掷物/爆破**：以携行量限制“连环爆破”路径；弹药在尸潮期前补给点保证“底线体验”。

## H. 章节难度曲线（非线性）

- 1 简单→2 适应→3 黑暗难点→4 护送缓→5 天台高峰→6 多路缓→7 噪音高峰→8 毒区持续→9 重装预热→10 多阶段终局。
- 峰谷交替，避免“持续高压疲劳”。

## I. 枪声吸引与潜行

- 枪械发声 30–60s 后触发区域尸潮判定；带消音附件/近战可延迟或规避；人类冲突自动引尸干扰，产生“强制混战”。

## J. 经济与补给（片段）

- 弹药/医疗为“硬通货”；商行信用点与势力工分并存；红区稀有材料驱动高风险跑图与史诗链条。
