# Gameplay Reference

## Project Snapshot
- 类型：第三人称合作生存射击（TPS Co-op）。
- 核心支柱：战术射击、资源管理、碎片化叙事。
- 模式：单人、分屏、在线合作；默认服务器权威。

## 数值锚点与不变量
- TTK 目标保持在 0.3–0.7 秒之间，长期平衡校验的参照。
- 普通游荡者 HP 锚点 150；其他敌人围绕此值扩展。
- 无随机暴击，只有弱点倍率，基础值 2.0x；能力或被动只调整弱点窗口。
- 技能数值固定，成长来自被动、属性与装备，避免数值通胀。

## 属性体系
- **Vitality 体力**：影响 MaxHP、护盾容量与击杀回复。完整公式见 `Docs/Design/Skills.md`。
- **Strength 力量**：提升武器伤害、护甲穿透与精英伤害加成。
- **Agility 敏捷**：决定移速、换弹速度、翻滚充能与翻滚后伤害窗口。
- **Perception 感知**：影响弱点倍率、弹药掉落、侦测范围与弱点连击奖励。

## 技能与槽位
- 键鼠默认：战术技能槽 1/2/3 分别为 `Q` / `E` / `C`，大招槽为 `X`。手柄默认：`LB` / `RB` / `D-Pad Up` + `LB+RB`（或 `Y`）触发大招。
- Lv5 解锁大招槽；Lv10/15/20 依次开放替换技能；翻滚与紧急闪避视为通用动作（`Space/Shift` 或手柄 `A` / `L3`）。
- 男主技能：战术标记、震撼手雷、战术翻滚；备选包括适应性装甲、处决打击、破甲射击；大招为战术超载、极限火力。
- 女主技能：战术扫描、救援掩护、紧急闪避；备选包括护盾发生器、感染抑制剂、战术无人机；大招为医疗站、生命复苏。
- 被动：通用（战术专家、速射手、掠夺者、生存大师）+ 男主/女主专属。

## 设计原则
- 机制制造挑战，不依赖数值堆叠；成长走递减曲线，强调选择与节奏。
- 使用锚点→联动的平衡流程：先调基础锚点，再处理派生系统。
- 护栏机制：翻滚、大招等通过能量或冷却限制，防止无限连锁。
- 环境红利：根据尸潮阶段或关卡事件触发额外增益和叙事节点。

## 调整与验证
- 平衡验证流程：实机游玩 > TTK 复核 > 不同 Build 测试 > 被动点数策略评估。
- 记录所有改动的设计意图，保持与 `Docs/Product/Roadmap.md` 的任务条目同步。
