# 文档1：《新秩序》技能系统核心数值（修正版）

------

## 0. 成长系统核心

等级：1-30级 双轨点数：属性点58（每级+2），技能点29（每级+1）

里程碑：

- Lv5：被动槽1 + 大招槽（默认键鼠 X）
- Lv10：被动槽2 + 可选技能1
- Lv15：被动槽3 + 可选技能2
- Lv20：第二武器槽 + 可选技能3
- Lv25：被动槽4 + 终极被动
- Lv30：满级奖励（全属性+2）

经验来源：游荡者10，猎手20，爬行者15，缠绕者25，干扰者30，吞噬者100，装甲士兵120，Boss500，通关1200-4000

## 1. 四维属性系统

男主初始（Lv1）：力量4，体力4，敏捷1，感知1 女主初始（Lv1）：力量1，体力2，敏捷4，感知3

### 体力（Vitality）

MaxHP公式：

- 基础100点
- 0-10点体力：每点+10生命（1点体力=110HP，10点=200HP）
- 11-20点体力：每点+6生命（20点体力=260HP）
- 21-30点体力：每点+4生命（30点体力=300HP）

护盾容量：

- 每1点体力：护盾容量上限+1.5%最大生命值
- 基础护盾上限：25%最大生命值
- 30点体力：护盾上限=70%最大生命值
- 示例：300HP角色，护盾上限210点

击杀回血：

- 每10点体力：击杀任意敌人回复3%最大生命值
- 10点体力：击杀回复3%最大生命值
- 20点体力：击杀回复6%最大生命值
- 30点体力：击杀回复9%最大生命值
- 示例：260HP角色，20点体力，击杀1个敌人回复15.6HP

------

### 力量（Strength）

武器伤害：

- 前10点：每点+2%武器伤害（10点=+20%）
- 中10点：每点+1.5%武器伤害（20点=+35%）
- 后10点：每点+1%武器伤害（30点=+45%）
- 示例：AK47基础35伤害，30点力量=51伤害

护甲穿透：

- 每1点力量：+1%护甲穿透
- 30点力量：+30%护甲穿透
- 说明：敌人护甲50点，穿透30%后剩余35点

精英伤害：

- 每10点力量：对精英/Boss额外+5%伤害
- 30点力量：对精英/Boss额外+15%伤害
- 示例：51伤害×1.15=58.65伤害

------

### 敏捷（Agility）

移动速度：

- 每1点敏捷：移速+0.8%
- 30点敏捷：移速+24%
- 说明：基础移速100%，30点敏捷=124%移速

换弹速度：

- 每1点敏捷：换弹时间-1.5%
- 30点敏捷：换弹时间-45%
- 示例：AK47基础换弹2.2秒，30点敏捷=1.21秒

翻滚充能：

- 每1点敏捷：翻滚充能时间-0.03秒
- 基础12秒/充能，30点敏捷=11.1秒/充能
- 说明：翻滚仍是3充能，递减机制不变

翻滚伤害加成：

- 每10点敏捷：翻滚后2秒内武器伤害+15%
- 30点敏捷：翻滚后2秒内武器伤害+45%

------

### 感知（Perception）

弱点倍率：

- 每1点感知：弱点伤害倍率+1%
- 基础弱点倍率×2.0，30点感知=×2.3
- 示例：35伤害，基础弱点70，30点感知弱点80.5

弹药掉落率：

- 每1点感知：弹药掉落概率+1%
- 30点感知：弹药掉落概率+30%
- 示例：普通敌人基础10%掉落，30点感知=40%掉落

侦测范围：

- 每1点感知：敌人标记/侦测范围+1%
- 30点感知：侦测范围+30%

弱点连击：

- 每10点感知：连续2次弱点命中后，下3发弱点伤害+30%
- 30点感知：下3发弱点伤害+90%
- 示例：80.5弱点伤害，触发后=152.95伤害

## 2. 男主技能（陈浩宇）

### 战术标记（技能槽1，默认键鼠 Q）

冷却：15秒 持续：8秒 效果：标记目标受到伤害+25%，弱点部位额外+10% 目标数量：1个（被动升级Lv3：2个） 击杀传播：标记目标死亡时，标记转移到5米内最近敌人，持续剩余时间

升级路径：

- Lv1：冷却时间-15%（15秒→12.75秒）
- Lv2：持续时间+3秒（8秒→11秒）
- Lv3：可同时标记2个目标

覆盖率计算：

- 基础：8秒/15秒=53%
- 满级+战术专家Lv3：11秒/10.2秒=108%（接近永久标记）
- 投入成本：标记升级3级（3点技能点）+战术专家Lv3（8点被动点）

------

### 震撼手雷（技能槽2，默认键鼠 E）

冷却：25秒 投掷：抛物线轨迹，2秒延迟爆炸 伤害：150点，爆炸半径3米 控制效果：

- 普通敌人：眩晕2秒
- 特殊敌人：硬直0.5秒
- 精英敌人：打断动作+0.3秒硬直
- Boss：仅打断动作 易伤效果：被炸敌人受到伤害+30%，持续5秒 尸潮红利：15米内同时存活>=10只敌人时，爆炸半径+50%（3米→4.5米）

------

### 战术翻滚（通用动作，键鼠默认 Space / Shift）

充能：3次，12秒/充能（敏捷降低充能时间） 无敌帧：前0.4秒无敌 位移距离：5米 递减惩罚：10秒内使用第3次翻滚，移速-30%持续3秒 CDR免疫：战术专家被动不影响翻滚充能时间

- 造成伤害时：伤害值的8%转化为装甲值
- 受到伤害时：伤害值的12%转化为装甲值
- 装甲上限：40%最大生命值（体力每10点+10%） 激活效果：
- 积累的装甲值转化为护盾
- 护盾持续8秒（体力每10点+2秒）
- 受到伤害-20%

------

### 处决打击（技能槽2 替换，Lv10）

冷却：20秒 范围：近战3米 条件：目标当前生命<30% 伤害：500%武器基础伤害 击杀回血：击杀目标后回复20%最大生命值

### 破甲射击（技能槽2 替换，Lv15）

## 10. 核心设计原则

### 架构（Lyra风格）

GA/GE挂在角色ASC，武器是SourceObject 装备时授予能力，卸载时移除

### 数值明确性

回血按最大生命值百分比（12%最大生命值） 不是吸血（按伤害百分比）

### 防滥用机制

标记可用于任何敌人（保持战术通用性） 回血仅精英/特殊触发（防止刷小怪） 标记和回血解耦（独立机制）

### 技能哲学（守望先锋）

15-30秒冷却保持战术性 技能辅助枪械，不替代枪械 主要伤害来源仍是武器（80%）
