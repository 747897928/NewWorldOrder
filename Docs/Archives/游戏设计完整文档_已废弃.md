## 一、核心游戏框架

### 1.1 游戏定位

**游戏类型**: 第三人称合作生存射击（TPS） **题材**: 丧尸末世 **核心玩法**: 双主角合作 + 策略射击 + RPG成长 **目标体验**: 合作是锦上添花，不是雪中送炭

**设计理念**:

- 射击占80%，技能占20%
- 技能是倍增器，不是替代品
- 15-30秒CD保持战术性
- 强调枪法和走位，技能锦上添花

### 1.2 游戏模式

**模式1: 单人模式**

- 玩家控制1个主角
- 不可在战斗中切换男/女主角
- 切换角色只能在Hub（安全营地）中预设
- 敌人数量按1人计算

**模式2: 本地分屏（2玩家）**

- 玩家A控制男主，玩家B控制女主
- 竖直分屏
- 敌人数量按2人计算（150%，不是200%）

**模式3: 在线合作（最多4玩家）**

- Listen Server架构
- 敌人数值和数量按人数动态调整
- Steam P2P网络

### 1.3 难度系统

**简单**:

- 敌人血量×0.7
- 敌人伤害×0.8
- 敌人数量-30%
- 推荐新手/休闲

**普通**:

- 敌人血量×1.0
- 敌人伤害×1.0
- 敌人数量100%
- 单人可过，双人轻松

**困难**:

- 敌人血量×1.3
- 敌人伤害×1.2
- 敌人数量+30%
- 推荐合作

**噩梦**:

- 敌人血量×2.0
- 敌人伤害×1.5
- 敌人数量+100%
- 精英数量翻倍
- 极限挑战

### 1.4 游戏规模

- **通关时长**: 8-15小时
- **章节数量**: 10-15章
- **章节结构**: 线性副本制
- **每章时长**: 30-60分钟
- **副本大小**: 0.5-1km²

### 1.5 Hub系统（安全营地）

**功能区**:

1. **娱乐设施**: 瑜伽、游泳、看电视
2. **仓库**: 制作传说武器、稀有服装
3. **训练场**: 测试武器、重置技能点、学习技能
4. **衣柜**: 更换服装外观（纯装饰）
5. **商店**: 购买普通武器、传说武器材料、普通服装设计图

**成长系统**:

- 属性加点: 体力、力量、敏捷、感知
- 技能树: 男女主独立技能树
- 技能槽: 4个被动槽 + 2个主动技能槽 + 1个大招槽
- 角色切换: 在Hub预设角色，战斗中不可切换

**商店规则（重要）**:

```
商店出售:
  - 普通武器
  - 传说武器制作材料（军用合金）
  - 普通服装设计图
  - 金币补充（氪金点）

商店不卖:
  - 消耗品（医疗道具、投掷道具）
  - 弹药（副本内拾取/补给站）
  - 稀有服装（需要制作）
  - 传说武器（需要制作）
```

**存档规则**:

永久保存:

```
- 角色成长: 等级、属性点、技能树、技能点
- 游戏进度: 已完成章节、已解锁服装、成就
- 货币: 金币
- 材料: 所有制作材料、设计图、势力徽章
- 武器: 所有获得的武器（包括传说武器）
- 服装: 所有解锁的服装
```

临时保存（副本内）:

```
- 弹药: 副本结束保留60%备弹
- 消耗品: 医疗道具和投掷道具副本结束清空
```


**男主初始（Lv1）**:

**女主初始（Lv1）**:

- 力量0、体力1、敏捷2、感知1
- 固定特性: +15%移速，-10%最大生命

- 女主: 力3、体4、敏5、感4 + 56点自由

### 2.2 体力（Vitality）

#### 效果1: 最大生命值（三段递减）

**公式**:

```cpp
MaxHP = BaseHP + VitalityBonus

BaseHP = 100

VitalityBonus计算（三段递减）:
- 0-10点: 每点+10 HP
  VitalityBonus = Vitality × 10

- 11-20点: 每点+6 HP
  VitalityBonus = 100 + (Vitality - 10) × 6

- 21-30点: 每点+4 HP
  VitalityBonus = 160 + (Vitality - 20) × 4
```

**关键数值点**:

- 0点: 100 HP
- 10点: 200 HP
- 20点: 260 HP
- 30点: 300 HP

**男主（+10%固定）**:

- 30点体力: 300 × 1.1 = 330 HP

**女主（-10%固定）**:

- 30点体力: 300 × 0.9 = 270 HP

**实现代码**:

```cpp
// UShootAttributeSet.h
UPROPERTY(BlueprintReadOnly, Category = "Attributes")
FGameplayAttributeData Vitality;

UPROPERTY(BlueprintReadOnly, Category = "Attributes")
FGameplayAttributeData MaxHP;

// UShootAttributeSet.cpp
float UShootAttributeSet::CalculateVitalityBonus(float Vitality) const
{
    if (Vitality <= 10.0f)
    {
        return Vitality * 10.0f;
    }
    else if (Vitality <= 20.0f)
    {
        return 100.0f + (Vitality - 10.0f) * 6.0f;
    }
    else
    {
        return 160.0f + (Vitality - 20.0f) * 4.0f;
    }
}

void UShootAttributeSet::PostGameplayEffectExecute(const FGameplayEffectModCallbackData& Data)
{
    if (Data.EvaluatedData.Attribute == GetVitalityAttribute())
    {
        float NewVitality = FMath::Clamp(Vitality.GetCurrentValue(), 0.0f, 30.0f);
        float VitalityBonus = CalculateVitalityBonus(NewVitality);
        
        // 应用角色固定特性
        float CharacterMultiplier = 1.0f;
        if (GetOwningActor()->ActorHasTag(FName("Character.Male")))
        {
            CharacterMultiplier = 1.1f; // 男主+10%
        }
        else if (GetOwningActor()->ActorHasTag(FName("Character.Female")))
        {
            CharacterMultiplier = 0.9f; // 女主-10%
        }
        
        MaxHP.SetBaseValue((100.0f + VitalityBonus) * CharacterMultiplier);
    }
}
```

#### 效果2: 护盾容量上限

**公式**:

```cpp
ShieldCapacity = (BasePercent + VitalityBonus) × MaxHP

BasePercent = 20%
VitalityBonus = Vitality × 1%
```

**关键数值点**:

- 0点: 20% MaxHP
- 10点: 30% MaxHP
- 20点: 40% MaxHP
- 30点: 50% MaxHP

**男主案例（30点体力）**:

- MaxHP: 330
- 护盾容量: 330 × 0.5 = 165

**护盾规则**:

- 护盾默认不存在
- 技能提供临时护盾（受此上限限制）
- 护盾破碎后15秒CD才能重新获得
- 护盾未破碎时，脱战5秒后开始恢复（每秒10%容量）

**实现代码**:

```cpp
// UShootAttributeSet.h
UPROPERTY(BlueprintReadOnly, Category = "Attributes")
FGameplayAttributeData Shield;

UPROPERTY(BlueprintReadOnly, Category = "Attributes")
FGameplayAttributeData ShieldCapacity;

// UShootAttributeSet.cpp
void UShootAttributeSet::PostGameplayEffectExecute(const FGameplayEffectModCallbackData& Data)
{
    if (Data.EvaluatedData.Attribute == GetVitalityAttribute())
    {
        float NewVitality = FMath::Clamp(Vitality.GetCurrentValue(), 0.0f, 30.0f);
        float ShieldPercent = 0.2f + (NewVitality * 0.01f);
        ShieldCapacity.SetBaseValue(MaxHP.GetCurrentValue() * ShieldPercent);
    }
    
    // 护盾破碎检测
    if (Data.EvaluatedData.Attribute == GetShieldAttribute())
    {
        if (Shield.GetCurrentValue() <= 0.0f && PreviousShieldValue > 0.0f)
        {
            // 护盾破碎，添加15秒CD Tag
            UAbilitySystemComponent* ASC = Data.Target.AbilitySystemComponent.Get();
            if (ASC)
            {
                FGameplayEffectContextHandle EffectContext = ASC->MakeEffectContext();
                FGameplayEffectSpecHandle SpecHandle = ASC->MakeOutgoingSpec(
                    GE_ShieldBroken_Cooldown, 1.0f, EffectContext
                );
                if (SpecHandle.IsValid())
                {
                    ASC->ApplyGameplayEffectSpecToSelf(*SpecHandle.Data.Get());
                }
            }
        }
        
        PreviousShieldValue = Shield.GetCurrentValue();
    }
}

private:
    float PreviousShieldValue = 0.0f;
```

#### 效果3: 减伤

**公式**:

```cpp
DamageReduction = Vitality × 0.2%

最终伤害 = IncomingDamage × (1 - DamageReduction)
```

**关键数值点**:

- 0点: 0%减伤
- 10点: 2%减伤
- 20点: 4%减伤
- 30点: 6%减伤

**配合生存大师被动Lv3**:

- 低血<30%时额外-30%减伤
- 总计: 6% + 30% = 36%减伤

**实现代码**:

```cpp
// UShootAttributeSet.h
UPROPERTY(BlueprintReadOnly, Category = "Attributes")
FGameplayAttributeData DamageReduction;

// UShootAttributeSet.cpp
void UShootAttributeSet::PostGameplayEffectExecute(const FGameplayEffectModCallbackData& Data)
{
    if (Data.EvaluatedData.Attribute == GetVitalityAttribute())
    {
        float NewVitality = FMath::Clamp(Vitality.GetCurrentValue(), 0.0f, 30.0f);
        DamageReduction.SetBaseValue(NewVitality * 0.002f);
    }
    
    // 受到伤害时应用减伤
    if (Data.EvaluatedData.Attribute == GetHPAttribute())
    {
        if (Data.EvaluatedData.Magnitude < 0.0f) // 负值表示伤害
        {
            float FinalDamage = -Data.EvaluatedData.Magnitude;
            float Reduction = GetDamageReduction();
            
            // 检查生存大师被动Lv3
            UAbilitySystemComponent* ASC = Data.Target.AbilitySystemComponent.Get();
            if (ASC && ASC->HasMatchingGameplayTag(
                FGameplayTag::RequestGameplayTag(FName("Passive.Survivalist.Level3"))))
            {
                float HPPercent = GetHP() / GetMaxHP();
                if (HPPercent < 0.3f)
                {
                    Reduction += 0.3f; // 额外+30%减伤
                }
            }
            
            FinalDamage *= (1.0f - Reduction);
            
            // 重新设置伤害值
            const_cast<FGameplayEffectModCallbackData&>(Data).EvaluatedData.Magnitude = -FinalDamage;
        }
    }
}
```

### 2.3 力量（Strength）

#### 效果1: 武器伤害加成（三段递减）

**公式**:

```cpp
DamageBonus计算（三段递减）:
- 0-10点: 每点+1.5%
  DamageBonus = Strength × 1.5%

- 11-20点: 每点+1%
  DamageBonus = 15% + (Strength - 10) × 1%

- 21-30点: 每点+0.8%
  DamageBonus = 25% + (Strength - 20) × 0.8%

最终伤害 = BaseDamage × (1 + DamageBonus)
```

**关键数值点**:

- 0点: +0%伤害
- 10点: +15%伤害
- 20点: +25%伤害
- 30点: +33%伤害

**示例（AK47基础35伤害）**:

- 0点力量: 35伤害
- 10点力量: 35 × 1.15 = 40.25伤害
- 20点力量: 35 × 1.25 = 43.75伤害
- 30点力量: 35 × 1.33 = 46.55伤害

**实现代码**:

```cpp
// UShootAttributeSet.h
UPROPERTY(BlueprintReadOnly, Category = "Attributes")
FGameplayAttributeData Strength;

// UShootAttributeSet.cpp
float UShootAttributeSet::CalculateStrengthDamageBonus(float Strength) const
{
    float DamageBonus = 0.0f;
    
    if (Strength <= 10.0f)
    {
        DamageBonus = Strength * 0.015f;
    }
    else if (Strength <= 20.0f)
    {
        DamageBonus = 0.15f + (Strength - 10.0f) * 0.01f;
    }
    else
    {
        DamageBonus = 0.25f + (Strength - 20.0f) * 0.008f;
    }
    
    return 1.0f + DamageBonus;
}

// 在伤害计算GA中调用
// UShootGA_Weapon_Fire_Rifle::CalculateFinalDamage
float StrengthBonus = SourceAttrSet->CalculateStrengthDamageBonus(SourceAttrSet->GetStrength());
FinalDamage *= StrengthBonus;
```

#### 效果2: 护甲穿透

**公式**:

```cpp
ArmorPenetration = Strength × 0.8%

有效护甲 = EnemyArmor × (1 - ArmorPenetration)
```

**关键数值点**:

- 0点: 0%穿透
- 10点: 8%穿透
- 20点: 16%穿透
- 30点: 24%穿透

**示例**:

- 敌人护甲50点，30点力量
- 有效护甲 = 50 × 0.76 = 38点

**实现代码**:

```cpp
// UShootAttributeSet.h
UPROPERTY(BlueprintReadOnly, Category = "Attributes")
FGameplayAttributeData ArmorPenetration;

// UShootAttributeSet.cpp
void UShootAttributeSet::PostGameplayEffectExecute(const FGameplayEffectModCallbackData& Data)
{
    if (Data.EvaluatedData.Attribute == GetStrengthAttribute())
    {
        float NewStrength = FMath::Clamp(Strength.GetCurrentValue(), 0.0f, 30.0f);
        ArmorPenetration.SetBaseValue(NewStrength * 0.008f);
    }
}

// 在伤害计算GA中应用护甲穿透
// UShootGA_Weapon_Fire_Rifle::CalculateFinalDamage
if (TargetAttrSet->GetArmor() > 0.0f)
{
    float Penetration = SourceAttrSet->GetArmorPenetration();
    float EffectiveArmor = TargetAttrSet->GetArmor() * (1.0f - Penetration);
    
    // 护甲减伤公式
    float ArmorReduction = EffectiveArmor / (EffectiveArmor + 100.0f);
    FinalDamage *= (1.0f - ArmorReduction);
}
```

### 2.4 敏捷（Agility）

#### 效果1: 移速加成

**公式**:

```cpp
MoveSpeedBonus = Agility × 1%

最终移速 = BaseMoveSpeed × (1 + MoveSpeedBonus) × CharacterMultiplier
```

**关键数值点**:

- 0点: 100%移速
- 10点: 110%移速
- 20点: 120%移速
- 30点: 130%移速

**男主（-5%固定）**:

- 30点敏捷: 130% × 0.95 = 123.5%移速

**女主（+15%固定）**:

- 30点敏捷: 130% × 1.15 = 149.5%移速

**实现代码**:

```cpp
// UShootCharacterMovementComponent.cpp
float UShootCharacterMovementComponent::GetMaxSpeed() const
{
    float BaseSpeed = Super::GetMaxSpeed();
    
    AShootCharacter* Character = Cast<AShootCharacter>(GetCharacterOwner());
    if (!Character) return BaseSpeed;
    
    UAbilitySystemComponent* ASC = Character->GetAbilitySystemComponent();
    if (!ASC) return BaseSpeed;
    
    const UShootAttributeSet* AttrSet = ASC->GetSet<UShootAttributeSet>();
    if (!AttrSet) return BaseSpeed;
    
    // 应用敏捷移速加成
    float AgilityBonus = AttrSet->GetAgility() * 0.01f;
    BaseSpeed *= (1.0f + AgilityBonus);
    
    // 应用角色固定特性
    if (Character->ActorHasTag(FName("Character.Male")))
    {
        BaseSpeed *= 0.95f; // 男主-5%
    }
    else if (Character->ActorHasTag(FName("Character.Female")))
    {
        BaseSpeed *= 1.15f; // 女主+15%
    }
    
    // 检查是否在射击
    if (Character->bIsFiring)
    {
        float ShootingPenalty = 0.4f - (AttrSet->GetAgility() * 0.01f);
        ShootingPenalty = FMath::Max(0.1f, ShootingPenalty); // 最少-10%
        BaseSpeed *= (1.0f - ShootingPenalty);
    }
    
    return BaseSpeed;
}
```

#### 效果2: 射击移速惩罚减免（新增）

**基础规则**: 所有角色射击时移速-40%

**公式**:

```cpp
惩罚减免 = Agility × 1%
射击时移速 = 正常移速 × (1 - (0.4 - 惩罚减免))
```

**数值点**:

- 0点敏捷: 射击时移速60%（-40%惩罚）
- 10点敏捷: 射击时移速70%（-30%惩罚）
- 20点敏捷: 射击时移速80%（-20%惩罚）
- 30点敏捷: 射击时移速90%（-10%惩罚）

**实战案例（30点敏捷男主）**:

- 正常移速: 123.5%
- 射击移速: 123.5% × 0.9 = 111.15%

#### 效果3: 换弹速度

**公式**:

```cpp
ReloadSpeedBonus = Agility × 1.5%

最终换弹时间 = BaseReloadTime × (1 - ReloadSpeedBonus)

动画播放速率 = 1 / (1 - ReloadSpeedBonus)
```

**关键数值点**:

- 0点: 换弹时间×100%（PlayRate=1.0）
- 10点: 换弹时间×85%（PlayRate=1.18）
- 20点: 换弹时间×70%（PlayRate=1.43）
- 30点: 换弹时间×55%（PlayRate=1.82）

**示例（AK47基础2.2秒）**:

- 0点敏捷: 2.2秒
- 10点敏捷: 2.2 × 0.85 = 1.87秒
- 20点敏捷: 2.2 × 0.7 = 1.54秒
- 30点敏捷: 2.2 × 0.55 = 1.21秒

**配合速射手被动Lv3（额外-40%）**:

- 总换弹时间: 2.2 × 0.55 × 0.6 = 0.726秒

**实现代码**:

```cpp
// UShootGameplayAbility_ReloadMagazine.cpp
void UShootGameplayAbility_ReloadMagazine::ActivateAbility(...)
{
    ARangedWeaponInstance* Weapon = GetWeaponInstance();
    UAbilitySystemComponent* ASC = GetAbilitySystemComponentFromActorInfo();
    const UShootAttributeSet* AttrSet = ASC->GetSet<UShootAttributeSet>();
    
    float BaseReloadTime = Weapon->Definition->ReloadTime;
    float AgilityBonus = AttrSet->GetAgility() * 0.015f;
    float PlayRate = 1.0f / (1.0f - AgilityBonus);
    
    // 速射手被动加成
    if (ASC->HasMatchingGameplayTag(FGameplayTag::RequestGameplayTag(FName("Passive.Speedloader.Level3"))))
    {
        PlayRate /= 0.6f; // 额外-40%
    }
    else if (ASC->HasMatchingGameplayTag(FGameplayTag::RequestGameplayTag(FName("Passive.Speedloader.Level2"))))
    {
        PlayRate /= 0.7f; // 额外-30%
    }
    else if (ASC->HasMatchingGameplayTag(FGameplayTag::RequestGameplayTag(FName("Passive.Speedloader.Level1"))))
    {
        PlayRate /= 0.8f; // 额外-20%
    }
    
    // 创建蒙太奇任务
    MontageTask = UAbilityTask_PlayMontageAndWait::CreatePlayMontageAndWaitProxy(
        this,
        NAME_None,
        CharacterReloadMontage,
        PlayRate,
        NAME_None,
        true,
        1.0f,
        0.0f,
        false
    );
    
    MontageTask->OnCompleted.AddDynamic(this, &UShootGameplayAbility_ReloadMagazine::K2_EndAbilityLocally);
    MontageTask->OnInterrupted.AddDynamic(this, &UShootGameplayAbility_ReloadMagazine::K2_EndAbility);
    MontageTask->OnCancelled.AddDynamic(this, &UShootGameplayAbility_ReloadMagazine::K2_EndAbility);
    MontageTask->ReadyForActivation();
    
    // 其他换弹逻辑...
}
```

#### 效果4: 翻滚充能系统

**基础规则**:

```
最大充能: 3次（固定）
充能时间: 10秒/次（固定，不受敏捷影响）
无敌时间: 0.4秒
翻滚距离: 5米
```

**翻滚递减机制（5秒内连续使用触发）**:

```
第1次翻滚:
- 无敌时间: 0.4秒
- 翻滚距离: 5米
- 无惩罚

第2次翻滚（5秒内）:
- 无敌时间: 0.3秒（-25%）
- 翻滚距离: 5米
- 无移速惩罚

第3次翻滚（5秒内）:
- 无敌时间: 0.2秒（-50%）
- 翻滚距离: 3.5米（-30%）
- 翻滚后移速-40%持续5秒

惩罚重置: 8秒未使用翻滚，重置所有惩罚计数
```

**实现代码**:

```cpp
// AShootCharacter.h
UPROPERTY(BlueprintReadOnly, Category = "Dodge")
int32 CurrentDodgeCharges = 3;

UPROPERTY(BlueprintReadOnly, Category = "Dodge")
int32 ConsecutiveDodges = 0; // 连续翻滚计数

UPROPERTY()
FTimerHandle DodgeResetTimerHandle;

UPROPERTY()
FTimerHandle DodgeRechargeTimerHandle;

UFUNCTION()
void PerformDodge();

UFUNCTION()
void ResetDodgePenalty();

UFUNCTION()
void RechargeDodge();

float GetCurrentDodgeInvulnerabilityTime() const;
float GetCurrentDodgeDistance() const;

// AShootCharacter.cpp
void AShootCharacter::PerformDodge()
{
    if (CurrentDodgeCharges <= 0) return;
    
    // 消耗充能
    CurrentDodgeCharges--;
    
    // 启动充能恢复（如果还没启动）
    if (!GetWorldTimerManager().IsTimerActive(DodgeRechargeTimerHandle))
    {
        GetWorldTimerManager().SetTimer(
            DodgeRechargeTimerHandle,
            this,
            &AShootCharacter::RechargeDodge,
            10.0f, // 固定10秒
            true
        );
    }
    
    // 增加连续翻滚计数
    ConsecutiveDodges++;
    
    // 重置惩罚计时器（8秒后重置）
    GetWorldTimerManager().ClearTimer(DodgeResetTimerHandle);
    GetWorldTimerManager().SetTimer(
        DodgeResetTimerHandle,
        this,
        &AShootCharacter::ResetDodgePenalty,
        8.0f,
        false
    );
    
    // 获取递减参数
    float InvulnerabilityTime = GetCurrentDodgeInvulnerabilityTime();
    float DodgeDistance = GetCurrentDodgeDistance();
    
    // 播放翻滚动画
    PlayDodgeMontage();
    
    // 应用无敌帧
    ApplyInvulnerability(InvulnerabilityTime);
    
    // 位移
    FVector DodgeDirection = GetActorForwardVector();
    LaunchCharacter(DodgeDirection * DodgeDistance * 100.0f, false, false);
    
    // 第3次翻滚惩罚
    if (ConsecutiveDodges >= 3)
    {
        // 应用移速减益GE
        ApplyMoveSpeedDebuff(0.4f, 5.0f);
    }
}

float AShootCharacter::GetCurrentDodgeInvulnerabilityTime() const
{
    switch (ConsecutiveDodges)
    {
        case 0: return 0.4f;
        case 1: return 0.3f;
        case 2:
        default: return 0.2f;
    }
}

float AShootCharacter::GetCurrentDodgeDistance() const
{
    if (ConsecutiveDodges >= 2)
    {
        return 3.5f; // -30%
    }
    return 5.0f;
}

void AShootCharacter::ResetDodgePenalty()
{
    ConsecutiveDodges = 0;
}

void AShootCharacter::RechargeDodge()
{
    if (CurrentDodgeCharges < 3)
    {
        CurrentDodgeCharges++;
        
        // 广播充能变化消息
        const FShootGameplayTags& ShootTags = FShootGameplayTags::Get();
        FDodgeChargeChangedMessage Msg;
        Msg.Owner = this;
        Msg.CurrentCharges = CurrentDodgeCharges;
        Msg.MaxCharges = 3;
        UGameplayMessageSubsystem::Get(this).BroadcastMessage(ShootTags.Msg_Dodge_ChargeChanged, Msg);
    }
    
    // 如果充满，停止计时器
    if (CurrentDodgeCharges >= 3)
    {
        GetWorldTimerManager().ClearTimer(DodgeRechargeTimerHandle);
    }
}
```

```cpp
                SourceASC->ApplyGameplayEffectSpecToTarget(*SpecHandle.Data.Get(), TargetASC);
```

```cpp
{
    // 造成伤害时
    if (Data.EvaluatedData.Attribute == GetOutgoingDamageAttribute())
    {
        float DamageDealt = Data.EvaluatedData.Magnitude;
        float ArmorGain = DamageDealt * 0.08f;

        FAdaptiveArmorChangedMessage Msg;
        Msg.Owner = GetOwningActor();
```

```cpp
UCLASS()
class UShootGA_Ultimate_TacticalOverload : public UShootGameplayAbility
{
    GENERATED_BODY()
    
public:
    UPROPERTY(EditDefaultsOnly, Category="Ultimate")
    float BaseDuration = 8.0f;
    
    UPROPERTY(EditDefaultsOnly, Category="Ultimate")
    float DurationPerKill = 1.0f;
    
    UPROPERTY(EditDefaultsOnly, Category="Ultimate")
    float MaxBonusDuration = 4.0f;
    
    UPROPERTY(EditDefaultsOnly, Category="Ultimate")
    TSubclassOf<UGameplayEffect> InfiniteAmmoEffectClass;
    
    UPROPERTY(EditDefaultsOnly, Category="Ultimate")
    TSubclassOf<UGameplayEffect> FireRateBoostEffectClass;
    
    UPROPERTY(EditDefaultsOnly, Category="Ultimate")
    TSubclassOf<UGameplayEffect> MoveSpeedBoostEffectClass;
    
    UPROPERTY(EditDefaultsOnly, Category="Ultimate")
    TSubclassOf<UGameplayEffect> ReloadSpeedBoostEffectClass;
    
protected:
    virtual void ActivateAbility(...) override;
    virtual void EndAbility(...) override;
    
    UFUNCTION()
    void OnEnemyKilled(FGameplayEventData Payload);
    
private:
    float BonusDurationAccumulated = 0.0f;
    FTimerHandle DurationTimerHandle;
    
    UPROPERTY()
    UAbilityTask_WaitGameplayEvent* WaitKillEventTask;
    
    TArray<FActiveGameplayEffectHandle> AppliedEffectHandles;
};

// UShootGA_Ultimate_TacticalOverload.cpp
void UShootGA_Ultimate_TacticalOverload::ActivateAbility(...)
{
    Super::ActivateAbility(...);
    
    UAbilitySystemComponent* ASC = GetAbilitySystemComponentFromActorInfo();
    if (!ASC) return;
    
    // 应用所有Buff GE
    TArray<TSubclassOf<UGameplayEffect>> EffectClasses = {
        InfiniteAmmoEffectClass,
        FireRateBoostEffectClass,
        MoveSpeedBoostEffectClass,
        ReloadSpeedBoostEffectClass
    };
    
    for (TSubclassOf<UGameplayEffect> EffectClass : EffectClasses)
    {
        if (EffectClass)
        {
            FGameplayEffectContextHandle EffectContext = ASC->MakeEffectContext();
            FGameplayEffectSpecHandle SpecHandle = ASC->MakeOutgoingSpec(EffectClass, GetAbilityLevel(), EffectContext);
            
            if (SpecHandle.IsValid())
            {
                FActiveGameplayEffectHandle EffectHandle = ASC->ApplyGameplayEffectSpecToSelf(*SpecHandle.Data.Get());
                AppliedEffectHandles.Add(EffectHandle);
            }
        }
    }
    
    // 监听击杀事件
    WaitKillEventTask = UAbilityTask_WaitGameplayEvent::WaitGameplayEvent(
        this,
        FGameplayTag::RequestGameplayTag(FName("GameplayEvent.Enemy.Killed")),
        nullptr,
        false, // OnlyTriggerOnce = false
        true
    );
    
    if (WaitKillEventTask)
    {
        WaitKillEventTask->EventReceived.AddDynamic(this, &UShootGA_Ultimate_TacticalOverload::OnEnemyKilled);
        WaitKillEventTask->ReadyForActivation();
    }
    
    // 启动持续时间定时器
    BonusDurationAccumulated = 0.0f;
    GetWorld()->GetTimerManager().SetTimer(
        DurationTimerHandle,
        [this]() { K2_EndAbility(); },
        BaseDuration,
        false
    );
}

void UShootGA_Ultimate_TacticalOverload::OnEnemyKilled(FGameplayEventData Payload)
{
    if (BonusDurationAccumulated >= MaxBonusDuration) return;
    
    BonusDurationAccumulated += DurationPerKill;
    BonusDurationAccumulated = FMath::Min(BonusDurationAccumulated, MaxBonusDuration);
    
    float RemainingTime = GetWorld()->GetTimerManager().GetTimerRemaining(DurationTimerHandle);
    if (RemainingTime > 0.0f)
    {
        GetWorld()->GetTimerManager().SetTimer(
            DurationTimerHandle,
            [this]() { K2_EndAbility(); },
            RemainingTime + DurationPerKill,
            false
        );
    }
}

void UShootGA_Ultimate_TacticalOverload::EndAbility(...)
{
    // 清理定时器
    if (DurationTimerHandle.IsValid())
    {
        GetWorld()->GetTimerManager().ClearTimer(DurationTimerHandle);
    }
    
    // 清理击杀监听
    if (WaitKillEventTask)
    {
        WaitKillEventTask->EndTask();
        WaitKillEventTask = nullptr;
    }
    
    // 移除所有Buff GE
    UAbilitySystemComponent* ASC = GetAbilitySystemComponentFromActorInfo();
    if (ASC)
    {
        for (FActiveGameplayEffectHandle& EffectHandle : AppliedEffectHandles)
        {
            if (EffectHandle.IsValid())
            {
                ASC->RemoveActiveGameplayEffect(EffectHandle);
            }
        }
    }
    AppliedEffectHandles.Empty();
    
    Super::EndAbility(...);
}
```

```cpp
void ADroneActor::BeginPlay()
{
    Super::BeginPlay();
    
    // 获取主人的被动等级
    AShootCharacter* Owner = Cast<AShootCharacter>(GetOwner());
    if (Owner && Owner->GetAbilitySystemComponent())
    {
        UAbilitySystemComponent* OwnerASC = Owner->GetAbilitySystemComponent();
        
        // 基础HP
        float BaseHP = 80.0f;
        
        // 智能辅助被动加成
        if (OwnerASC->HasMatchingGameplayTag(FGameplayTag::RequestGameplayTag(FName("Passive.SmartAssist.Level3"))))
        {
            BaseHP += 50.0f;
            DamageMultiplier = 1.5f;
            HealingMultiplier = 1.5f;
            Duration += 5.0f;
            bEnableSmartMode = true;
            bExplodeOnDeath = true;
        }
        else if (OwnerASC->HasMatchingGameplayTag(FGameplayTag::RequestGameplayTag(FName("Passive.SmartAssist.Level2"))))
        {
            BaseHP += 50.0f;
            DamageMultiplier = 1.5f;
            HealingMultiplier = 1.5f;
        }
        else if (OwnerASC->HasMatchingGameplayTag(FGameplayTag::RequestGameplayTag(FName("Passive.SmartAssist.Level1"))))
        {
            BaseHP += 50.0f;
        }
        
        // 体力加成
        const UShootAttributeSet* OwnerAttrSet = OwnerASC->GetSet<UShootAttributeSet>();
        BaseHP += FMath::Floor(OwnerAttrSet->GetVitality() / 10.0f) * 25.0f;
        
        // 设置HP
        UAbilitySystemComponent* DroneASC = GetAbilitySystemComponent();
        const UShootAttributeSet* DroneAttrSet = DroneASC->GetSet<UShootAttributeSet>();
        const_cast<UShootAttributeSet*>(DroneAttrSet)->MaxHP.SetBaseValue(BaseHP);
        const_cast<UShootAttributeSet*>(DroneAttrSet)->HP.SetBaseValue(BaseHP);
    }

void ADroneActor::Tick(float DeltaTime)
{
    Super::Tick(DeltaTime);
    
    if (!bEnableSmartMode) return;
    
    // 检测周围环境，自动切换模式
    AShootCharacter* Owner = Cast<AShootCharacter>(GetOwner());
    if (!Owner) return;
    
    // 检测受伤队友
    bool bHasInjuredAlly = CheckForInjuredAllies();
    
    // 检测附近敌人
    int32 NearbyEnemyCount = CountNearbyEnemies();
    
    // 智能决策
    if (bHasInjuredAlly)
    {
        SwitchToMode(EDroneMode::Healing);
    }
    else if (NearbyEnemyCount >= 3)
    {
        SwitchToMode(EDroneMode::Defense);
    }
    else
    {
        SwitchToMode(EDroneMode::Scouting);
    }
}

{
    if (bExplodeOnDeath)
    {
        // 范围伤害（3米）
        TArray<FOverlapResult> Overlaps;
        FCollisionQueryParams QueryParams;
        QueryParams.AddIgnoredActor(this);
        QueryParams.AddIgnoredActor(GetOwner());
        
        GetWorld()->OverlapMultiByChannel(
            Overlaps,
            GetActorLocation(),
            FQuat::Identity,
            ECC_Pawn,
            FCollisionShape::MakeSphere(300.0f),
            QueryParams
        );
        
        for (const FOverlapResult& Overlap : Overlaps)
        {
            if (Overlap.GetActor() && Overlap.GetActor()->ActorHasTag(FName("Enemy")))
            {
                UAbilitySystemComponent* TargetASC = UAbilitySystemBlueprintLibrary::GetAbilitySystemComponent(Overlap.GetActor());
                if (TargetASC)
                {
                    ApplyDamageToTarget(TargetASC, 150.0f);
                    ApplyStunEffect(TargetASC, 2.0f);
                }
            }
        }
        
        // 播放爆炸特效
        SpawnExplosionEffect();
    }
    
    Destroy();
}
```

```cpp
        {
            HealPercent = 0.04f;
        }
    }
    else if (ASC->HasMatchingGameplayTag(FGameplayTag::RequestGameplayTag(FName("Passive.MarkedHunter.Level2"))))
    {
```

```cpp
// 在UShootAttributeSet中监听护盾破碎
void UShootAttributeSet::PostGameplayEffectExecute(const FGameplayEffectModCallbackData& Data)
{
    if (Data.EvaluatedData.Attribute == GetShieldAttribute())
    {
        if (Shield.GetCurrentValue() <= 0.0f && PreviousShieldValue > 0.0f)
        {
            // 护盾破碎
            UAbilitySystemComponent* ASC = Data.Target.AbilitySystemComponent.Get();
            if (ASC && ASC->HasMatchingGameplayTag(FGameplayTag::RequestGameplayTag(FName("Passive.ArmorEnhancement.Level3"))))
            {
                // 触发爆炸
                float ExplosionDamage = PreviousShieldValue * 0.5f;
                FVector Location = GetOwningActor()->GetActorLocation();
                
                // 范围伤害（3米）
                TArray<FOverlapResult> Overlaps;
                FCollisionQueryParams QueryParams;
                QueryParams.AddIgnoredActor(GetOwningActor());
                
                GetWorld()->OverlapMultiByChannel(
                    Overlaps,
                    Location,
                    FQuat::Identity,
                    ECC_Pawn,
                    FCollisionShape::MakeSphere(300.0f),
                    QueryParams
                );
                
                for (const FOverlapResult& Overlap : Overlaps)
                {
                    if (Overlap.GetActor() && Overlap.GetActor()->ActorHasTag(FName("Enemy")))
                    {
                        UAbilitySystemComponent* TargetASC = UAbilitySystemBlueprintLibrary::GetAbilitySystemComponent(Overlap.GetActor());
                        if (TargetASC)
                        {
                            ApplyDamageToTarget(TargetASC, ExplosionDamage);
                        }
                    }
                }
            }
        }
        
        PreviousShieldValue = Shield.GetCurrentValue();
    }
}
```

### 5.9 HitscanWeaponInstance扩展

基于你的射击GA代码，Hitscan武器需要额外的扩散系统:

```cpp
// 在AHitscanWeaponInstance中添加
UPROPERTY(EditDefaultsOnly, Category="Spread")
float SpreadExponent = 1.0f;                      // 扩散指数（控制聚集程度）

UPROPERTY(EditDefaultsOnly, Category="Spread")
float BulletTraceSweepRadius = 0.0f;              // 子弹扫描半径（0=线性射线）

UPROPERTY()
float CurrentSpread = 0.0f;                       // 当前扩散值

UPROPERTY()
float LastFireTime = 0.0f;                        // 上次开火时间

// 扩散计算
float GetCalculatedSpreadAngle() const
{
    if (!Definition) return 0.0f;
    
    // 从CSV读取BaseSpreadAngle
    return Definition->BaseSpreadAngle;
}

float GetCalculatedSpreadAngleMultiplier() const
{
    if (!Definition) return 1.0f;
    
    // 扩散值 = CurrentSpread / MaxSpreadAngle
    float MaxSpread = Definition->MaxSpreadAngle;
    if (MaxSpread <= 0.0f) return 1.0f;
    
    return CurrentSpread / MaxSpread;
}

void UpdateFiringTime()
{
    LastFireTime = GetWorld()->GetTimeSeconds();
}

void AddSpread()
{
    if (!Definition) return;
    
    CurrentSpread = FMath::Min(CurrentSpread + Definition->SpreadPerShot, Definition->MaxSpreadAngle);
}

// Tick中恢复扩散
void AHitscanWeaponInstance::Tick(float DeltaTime)
{
    Super::Tick(DeltaTime);
    
    if (Definition && CurrentSpread > 0.0f)
    {
        float TimeSinceLastFire = GetWorld()->GetTimeSeconds() - LastFireTime;
        if (TimeSinceLastFire > 0.1f) // 停火0.1秒后开始恢复
        {
            CurrentSpread = FMath::Max(0.0f, CurrentSpread - Definition->SpreadRecovery * DeltaTime);
        }
    }
}

float GetSpreadExponent() const { return SpreadExponent; }
float GetBulletTraceSweepRadius() const { return BulletTraceSweepRadius; }
int32 GetBulletsPerCartridge() const
{
    return Definition ? Definition->BulletsPerShot : 1;
}
```

```cpp
void AShootGameMode::UpdateEnemyScaling()

    // 遍历所有已生成的敌人，重新应用缩放
    for (AEnemyBase* Enemy : SpawnedEnemies)
    {
        if (Enemy && !Enemy->IsPendingKillPending())

}

void AShootGameMode::ApplyScalingToEnemy(AEnemyBase* Enemy)
{
    UAbilitySystemComponent* EnemyASC = Enemy->GetAbilitySystemComponent();
    if (!EnemyASC) return;
    
    // 移除旧的玩家数量缩放GE
    EnemyASC->RemoveActiveGameplayEffectBySourceEffect(GE_EnemyScaling_2Players, EnemyASC);
    EnemyASC->RemoveActiveGameplayEffectBySourceEffect(GE_EnemyScaling_3Players, EnemyASC);
    EnemyASC->RemoveActiveGameplayEffectBySourceEffect(GE_EnemyScaling_4Players, EnemyASC);
    
    // 应用章节缩放GE（仅生成时应用一次）
    if (GE_ChapterScaling.IsValidIndex(CurrentChapterIndex - 1))
    {
        if (!EnemyASC->HasMatchingGameplayTag(FGameplayTag::RequestGameplayTag(FName("Scaling.Chapter.Applied"))))
        {
            FGameplayEffectContextHandle EffectContext = EnemyASC->MakeEffectContext();
            FGameplayEffectSpecHandle SpecHandle = EnemyASC->MakeOutgoingSpec(
                GE_ChapterScaling[CurrentChapterIndex - 1], 1.0f, EffectContext
            );
            
            if (SpecHandle.IsValid())
            {
                EnemyASC->ApplyGameplayEffectSpecToSelf(*SpecHandle.Data.Get());
            }
        }
    }
    
    // 应用难度缩放GE（仅生成时应用一次）
    if (!EnemyASC->HasMatchingGameplayTag(FGameplayTag::RequestGameplayTag(FName("Scaling.Difficulty.Applied"))))
    {
        TSubclassOf<UGameplayEffect> DifficultyGE = nullptr;
        switch (CurrentDifficulty)
        {
            case EDifficultyLevel::Easy:
                DifficultyGE = GE_DifficultyScaling_Easy;
                break;
            case EDifficultyLevel::Hard:
                DifficultyGE = GE_DifficultyScaling_Hard;
                break;
            case EDifficultyLevel::Nightmare:
                DifficultyGE = GE_DifficultyScaling_Nightmare;
                break;
            default:
                break; // Normal不需要额外GE
        }
        
        if (DifficultyGE)
        {
            FGameplayEffectContextHandle EffectContext = EnemyASC->MakeEffectContext();
            FGameplayEffectSpecHandle SpecHandle = EnemyASC->MakeOutgoingSpec(
                DifficultyGE, 1.0f, EffectContext
            );
            
            if (SpecHandle.IsValid())
            {
                EnemyASC->ApplyGameplayEffectSpecToSelf(*SpecHandle.Data.Get());
            }
        }
    }
    
    // 应用玩家数量缩放GE（动态调整）
    TSubclassOf<UGameplayEffect> PlayerCountGE = nullptr;
    switch (CurrentPlayerCount)
    {
        case 2:
            PlayerCountGE = GE_EnemyScaling_2Players;
            break;
        case 3:
            PlayerCountGE = GE_EnemyScaling_3Players;
            break;
        case 4:
            PlayerCountGE = GE_EnemyScaling_4Players;
            break;
        default:
            break; // 1人不需要额外GE
    }
    
    if (PlayerCountGE)
    {
        FGameplayEffectContextHandle EffectContext = EnemyASC->MakeEffectContext();
        FGameplayEffectSpecHandle SpecHandle = EnemyASC->MakeOutgoingSpec(
            PlayerCountGE, 1.0f, EffectContext
        );
        
        if (SpecHandle.IsValid())
        {
            EnemyASC->ApplyGameplayEffectSpecToSelf(*SpecHandle.Data.Get());
        }
    }
    
    // 精英敌人额外缩放
    if (Enemy->bIsElite && CurrentPlayerCount > 1)
    {
        float EliteMultiplier = 1.0f;
        switch (CurrentPlayerCount)
        {
            case 2: EliteMultiplier = 1.3f; break;
            case 3: EliteMultiplier = 1.6f; break;
            case 4: EliteMultiplier = 2.0f; break;
        }
        
        // 应用精英缩放（动态创建GE）
        UGameplayEffect* EliteGE = NewObject<UGameplayEffect>(this);
        EliteGE->DurationPolicy = EGameplayEffectDurationType::Infinite;
        
        FGameplayModifierInfo Modifier;
        Modifier.Attribute = UShootAttributeSet::GetMaxHPAttribute();
        Modifier.ModifierOp = EGameplayModOp::Multiply;
        Modifier.ModifierMagnitude = FScalableFloat(EliteMultiplier);
        EliteGE->Modifiers.Add(Modifier);
        
        FGameplayEffectContextHandle EffectContext = EnemyASC->MakeEffectContext();
        FGameplayEffectSpec SpecData(EliteGE, EffectContext, 1.0f);
        
        EnemyASC->ApplyGameplayEffectSpecToSelf(SpecData);
    }
}
```

### 10.2 完整伤害计算流程

**计算公式**:

```cpp
float UShootGA_Weapon_Fire_Rifle::CalculateFinalDamage(
    const FHitResult& Hit, 
    float Distance,
    UAbilitySystemComponent* SourceASC,
    UAbilitySystemComponent* TargetASC,
    ARangedWeaponInstance* Weapon)
{
    const UShootAttributeSet* SourceAttrSet = SourceASC->GetSet<UShootAttributeSet>();
    const UShootAttributeSet* TargetAttrSet = TargetASC->GetSet<UShootAttributeSet>();
    
    // 1. 基础伤害
    float FinalDamage = Weapon->GetBaseDamage();
    
    // 2. 距离衰减
    float FalloffMult = Weapon->GetDistanceAttenuation(Distance);
    FinalDamage *= FalloffMult;
    
    // 3. 力量加成（三段递减）
    float Strength = SourceAttrSet->GetStrength();
    float StrengthBonus = SourceAttrSet->CalculateStrengthDamageBonus(Strength);
    FinalDamage *= StrengthBonus;
    
    // 4. 护甲穿透
    if (TargetAttrSet->GetArmor() > 0.0f)
    {
        float Penetration = SourceAttrSet->GetArmorPenetration();
        float EffectiveArmor = TargetAttrSet->GetArmor() * (1.0f - Penetration);
        
        // 护甲减伤公式
        float ArmorReduction = EffectiveArmor / (EffectiveArmor + 100.0f);
        FinalDamage *= (1.0f - ArmorReduction);
    }
    
    // 5. 爆头/暴击判定（互斥，通过物理材质Tag判定）
    bool bIsHeadshot = false;
    
    if (const UPhysicalMaterialWithTags* PhysMat = Cast<UPhysicalMaterialWithTags>(Hit.PhysMaterial.Get()))
    {
        if (PhysMat->Tags.HasTag(FShootGameplayTags::Get().Gameplay_Zone_WeakSpot))
        {
            bIsHeadshot = true;
        }
    }
    
    if (bIsHeadshot)
    {
        // 爆头自动视为暴击
        float HeadshotMult = 2.0f + (SourceAttrSet->GetPerception() * 0.015f);
        
        // 狙击枪特殊倍率
        if (Weapon->Definition && Weapon->Definition->WeaponType == EWeaponType::Sniper)
        {
            HeadshotMult = 2.5f + (SourceAttrSet->GetPerception() * 0.015f);
        }
        
        FinalDamage *= HeadshotMult;
    }
    else
    {
        // 身体命中，按概率触发暴击
        float CritChance = SourceAttrSet->GetCriticalChance();
        bool bIsCritical = FMath::FRandRange(0.0f, 1.0f) < CritChance;
        
        // 检查精准专家被动Lv3（连续2次暴击，强制触发）
        AShootCharacter* SourceCharacter = Cast<AShootCharacter>(SourceASC->GetAvatarActor());
        if (SourceCharacter && SourceCharacter->ConsecutiveCrits >= 2)
        {
            if (SourceASC->HasMatchingGameplayTag(FGameplayTag::RequestGameplayTag(FName("Passive.Precision.Level3"))))
            {
                bIsCritical = true;
                SourceCharacter->ConsecutiveCrits = 0;
            }
        }
        
        if (bIsCritical)
        {
            float CritMultiplier = 1.2f;
            
            // 精准专家被动加成
            if (SourceASC->HasMatchingGameplayTag(FGameplayTag::RequestGameplayTag(FName("Passive.Precision.Level3"))))
            {
                CritMultiplier = 1.56f;
            }
            else if (SourceASC->HasMatchingGameplayTag(FGameplayTag::RequestGameplayTag(FName("Passive.Precision.Level2"))))
            {
                CritMultiplier = 1.44f;
            }
            else if (SourceASC->HasMatchingGameplayTag(FGameplayTag::RequestGameplayTag(FName("Passive.Precision.Level1"))))
            {
                CritMultiplier = 1.32f;
            }
            
            FinalDamage *= CritMultiplier;
            
            // 追踪连续暴击
            if (SourceCharacter)
            {
                SourceCharacter->ConsecutiveCrits++;
            }
        }
        else
        {
            // 重置连击
            if (SourceCharacter)
            {
                SourceCharacter->ConsecutiveCrits = 0;
            }
        }
    }
    
    // 6. 技能增伤（乘法叠加）
    if (TargetASC->HasMatchingGameplayTag(FGameplayTag::RequestGameplayTag(FName("Status.Marked"))))
    {
        FinalDamage *= 1.25f; // 标记+25%
    }
    
    if (TargetASC->HasMatchingGameplayTag(FGameplayTag::RequestGameplayTag(FName("Status.Vulnerable"))))
    {
        FinalDamage *= 1.30f; // 易伤+30%
    }
    
    // 7. 体力减伤（目标受伤时）
    float DamageReduction = TargetAttrSet->GetDamageReduction();
    
    // 检查生存大师被动Lv3
    if (TargetASC->HasMatchingGameplayTag(FGameplayTag::RequestGameplayTag(FName("Passive.Survivalist.Level3"))))
    {
        float HPPercent = TargetAttrSet->GetHP() / TargetAttrSet->GetMaxHP();
        if (HPPercent < 0.3f)
        {
            DamageReduction += 0.3f; // 额外+30%减伤
        }
    }
    
    FinalDamage *= (1.0f - DamageReduction);
    
    return FinalDamage;
}
```

```cpp
void UShootGA_Weapon_Fire_Rifle::ProcessHits(const FGameplayAbilityTargetDataHandle& TargetData)
{
    UAbilitySystemComponent* SourceASC = GetAbilitySystemComponentFromActorInfo();
    const UShootAttributeSet* SourceAttrSet = SourceASC->GetSet<UShootAttributeSet>();
    
    const int32 HitCount = UAbilitySystemBlueprintLibrary::GetDataCountFromTargetData(TargetData);
    const bool bIsAuthority = K2_HasAuthority();
    
    // 用于UI通信的命中信息数组
    TArray<FShootReticleHitLocation> HitLocations;
    
    for (int32 i = 0; i < HitCount; ++i)
    {
        const FHitResult& Hit = UAbilitySystemBlueprintLibrary::GetHitResultFromTargetData(TargetData, i);
        
        // 只处理真实命中
        if (!Hit.bBlockingHit) continue;
        
        // 1. 准备UI命中标记数据
        FShootReticleHitLocation HitLocation;
        HitLocation.WorldPosition = Hit.ImpactPoint.IsZero() ? Hit.TraceEnd : Hit.ImpactPoint;
        HitLocation.bHasWorldPosition = true;
        HitLocation.bShowAsSuccess = true;
        
        // 检查是否是弱点命中
        bool bIsHeadshot = false;
        if (const UPhysicalMaterialWithTags* PhysMat = Cast<UPhysicalMaterialWithTags>(Hit.PhysMaterial.Get()))
        {
            if (PhysMat->Tags.HasTag(FShootGameplayTags::Get().Gameplay_Zone_WeakSpot))
            {
                HitLocation.HitZone = FShootGameplayTags::Get().Gameplay_Zone_WeakSpot;
                bIsHeadshot = true;
            }
        }
        
        // 2. 播放命中特效（所有客户端）
        if (ImpactGameplayCueTag.IsValid())
        {
            FGameplayCueParameters ImpactParams = 
                UGameplayCueFunctionLibrary::MakeGameplayCueParametersFromHitResult(Hit);
            K2_ExecuteGameplayCueWithParams(ImpactGameplayCueTag, ImpactParams);
        }
        
        // 3. 服务器：应用伤害
        if (bIsAuthority)
        {
            AActor* TargetActor = Hit.GetActor();
            if (!TargetActor) continue;
            
            UAbilitySystemComponent* TargetASC = UAbilitySystemBlueprintLibrary::GetAbilitySystemComponent(TargetActor);
            if (!TargetASC) continue;
            
            ARangedWeaponInstance* Weapon = GetWeaponInstance();
            if (!Weapon) continue;
            
            // 计算距离
            float Distance = FVector::Dist(Hit.TraceStart, Hit.ImpactPoint);
            
            // 计算最终伤害
            float FinalDamage = CalculateFinalDamage(Hit, Distance, SourceASC, TargetASC, Weapon);
            
            // 记录伤害值（用于UI显示）
            HitLocation.Damage = FinalDamage;
            HitLocation.bIsCritical = !bIsHeadshot && (FMath::FRandRange(0.0f, 1.0f) < SourceAttrSet->GetCriticalChance());
            
            // 应用伤害GE
            if (DamageGameplayEffectClass)
            {
                FGameplayEffectContextHandle EffectContext = SourceASC->MakeEffectContext();
                EffectContext.AddSourceObject(Weapon);
                EffectContext.AddInstigator(GetAvatarActorFromActorInfo(), GetAvatarActorFromActorInfo());
                EffectContext.AddHitResult(Hit);
                
                FGameplayEffectSpecHandle SpecHandle = SourceASC->MakeOutgoingSpec(
                    DamageGameplayEffectClass, 
                    GetAbilityLevel(), 
                    EffectContext
                );
                
                if (SpecHandle.IsValid())
                {
                    SpecHandle.Data->SetSetByCallerMagnitude(
                        FShootGameplayTags::Get().SetByCaller_Damage,
                        FinalDamage
                    );
                    
                    SourceASC->ApplyGameplayEffectSpecToTarget(*SpecHandle.Data.Get(), TargetASC);
                }
            }
        }
        
        HitLocations.Add(HitLocation);
    }
    
    // 4. 广播UI命中通知（仅本地玩家）
    if (IsLocallyControlled() && HitLocations.Num() > 0)
    {
        BroadcastReticleHitNotify(HitLocations);
    }
}
```

```cpp
void UShootDamageNumberComponent::BeginPlay()
{
    Super::BeginPlay();
    
    // 注册监听器

    HitNotifyListenerHandle = UGameplayMessageSubsystem::Get(this).RegisterListener(

void UShootDamageNumberComponent::OnHitNotifyReceived(FGameplayTag Channel, const FShootReticleHitNotifyMessage& Message)
{
    for (const FShootReticleHitLocation& Hit : Message.HitMarkers)
    {
        if (!Hit.bHasWorldPosition) continue;
        
        // 选择合适的Niagara系统
        UNiagaraSystem* SystemToSpawn = DamageNumberSystem;
        if (Hit.bIsHeadshot)
        {
            SystemToSpawn = HeadshotNumberSystem;
        }
        else if (Hit.bIsCritical)
        {
            SystemToSpawn = CriticalNumberSystem;
        }
        
        if (SystemToSpawn)
        {
            // 生成Niagara粒子
            UNiagaraComponent* NiagaraComp = UNiagaraFunctionLibrary::SpawnSystemAtLocation(
                GetWorld(),
                SystemToSpawn,
                Hit.WorldPosition,
                FRotator::ZeroRotator,
                FVector(1.0f),
                true,
                true,
                ENCPoolMethod::None,
                true
            );
            
            if (NiagaraComp)
            {
                // 设置伤害数值参数
                NiagaraComp->SetFloatParameter(FName("DamageValue"), Hit.Damage);
            }
        }
    }
}
```

```cpp
protected:
    virtual void ProcessHits(const FGameplayAbilityTargetDataHandle& TargetData) override
    {
        Super::ProcessHits(TargetData);
                
        ARangedWeaponInstance* Weapon = GetWeaponInstance();
        if (!Weapon) return;
                
        for (int32 i = 0; i < TargetData.Num(); ++i)
        {
            const FHitResult& Hit = GetHitResult(TargetData, i);

            if (bIsHeadshot)
            {
                Weapon->bGuaranteedCritNextShot = true;
                                
                // 穿透检测
                CheckAndApplyPenetration(Hit);
            }
            else
            {

            }
        }
```

## 十三、关键技术要点总结

### 13.1 GAS架构适配

你的代码架构:
- 玩家: ASC在PlayerState上
- AI: ASC在ACharacter上
- 武器: SourceObject传递武器实例
- 弹药: 服务器权威+客户端预测

### 13.2 关键实现点

**属性系统**:
- AttributeSet: `UShootAttributeSet`
- 派生属性在`PostGameplayEffectExecute`中计算
- 三段递减公式在AttributeSet中实现

**技能系统**:
- GA基类: `UShootGameplayAbility`
- 技能槽: 在Character中管理（4被动+2主动+1大招）
- CD管理: Cooldown GE + 战术专家被动修改器
- 充能追踪: `UltimateCharge`属性

**被动系统**:
- 被动GE: Infinite Duration
- Granted Tags: `Passive.XXX.LevelX`
- 效果检查: `HasMatchingGameplayTag`
- 连击追踪: Character中的`ConsecutiveCrits`

**武器系统**:
- 定义: `UWeaponDefinition` (DataAsset)
- 实例: `ARangedWeaponInstance` (Actor)
- GA绑定: GrantedAbilities在装备时授予
- 弹药管理: CurrentAmmo/PredictedAmmo双值系统

**敌人系统**:
- 缩放GE: GameMode中管理
- 动态调整: 玩家加入/离开时`UpdateEnemyScaling`
- 精英标记: `bIsElite`布尔值

**伤害计算**:
- 物理材质Tag判定弱点: `UPhysicalMaterialWithTags`
- 伤害乘区: 按顺序应用
- 爆头/暴击: 互斥机制
- UI通信: `UGameplayMessageSubsystem`

**材料系统**:
- 永久保存: 军用合金、势力徽章、设计图、服装碎片、金币
- 制作系统: 在Hub仓库进行
- 传说武器: 需要徽章+设计图+材料+金币

**补给系统**:
- 弹药: 副本内掉落，结束保留60%备弹
- 消耗品: 副本内拾取，结束清空
- 补给站: 每副本2-3个，递减补充

**UI通信**:
- 使用`UGameplayMessageSubsystem`广播消息
- Niagara粒子显示伤害数字（参考Lyra）
- 消息结构体定义在独立头文件
