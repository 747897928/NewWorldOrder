# 生化模式总览

# 产品目标

- 建立一个以“少量初始感染者追击多数人类”为核心的回合制玩法。
- 人类通过持续火力、路线选择和高处守点坚持到回合结束；感染者通过近战接触或模式定义的感染攻击扩大阵营。
- 每局属性、等级、战斗装备和技能只属于本次副本，不进入账号存档。
- 第一阶段允许使用占位角色、占位动画和白盒环境，优先验证规则、网络、分屏和地图攻防结构。

# 首个版本范围

- 新建 `TestMap_Biochemical` 白盒地图。
- 三个强度不同的守点、一个闭合外环和至少三条横向连接路线。
- GameMode 回合状态机、倒计时、初始感染者、感染转换、胜负和下一回合。
- Human/Infected 阵营与 AbilitySet/GameplayEffect 切换。
- 生化模式 HUD：阶段、倒计时、两阵营人数和回合结果。
- Listen Server 为首要联机验收；本地分屏继续保证每个 LocalPlayer UI 隔离。

# 非首个版本范围

- 最终美术场景、完整感染动画、专属感染者骨骼和全部音效。
- 英雄、补给箱、僵尸进化、特殊感染者技能和商城经济。
- GameFeature 插件化或 DLC 热装卸。
