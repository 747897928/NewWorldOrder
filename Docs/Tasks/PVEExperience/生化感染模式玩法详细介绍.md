# 生化感染模式玩法详细介绍

## 1. 模式定位

生化感染模式是一种多人对抗感染玩法。每名玩家从人类开始，通过射击、走位、技能构筑和地图协作争取生存时间。僵尸通过追击、压制和感染扩大队伍。玩家被感染后继续参与当前回合，阵营改变带来新的目标、能力和操作方式。

一场完整对局由多个独立回合组成。单个回合解决一次人类与僵尸的攻防，多个回合共同完成整场对局的结果与奖励。

模式的核心体验由三件事组成：

- 阵营随回合进程发生变化，任何一次感染都会改变战场人口和追击压力。
- 每名玩家通过局内技能形成临时战斗构筑，技能选择影响生存、追击、控制、救援和感染效率。
- 回合在最后人类、特殊角色、地图目标和最终决战阶段形成强烈的节奏变化。

## 2. Match 与 Round

### Match

Match 是一次完整的多人对局。它负责承载玩家进入、多个回合、局内技能构筑、局内等级、局内货币、变体规则和最终结算。

Match 级内容可以跨回合保留：

- 局内获得的主动技能和技能等级。
- 当前回合外仍有效的局内成长。
- 由模式开启的局内金币、经验、生化 Z 或其他进度。
- 多回合共享的角色外观和玩家操作偏好。

### Round

Round 是一次从准备阶段到回合结束的完整感染战斗。回合结束后，下一回合重新建立人类准备阶段，回合生命值、感染状态、回合死亡和回合地图状态按规则重置。

回合流程会根据模式保留 Match 级技能构筑，也可以在回合开始时重置部分临时能力。每种规则应在玩法说明中明确标注保留范围。

## 3. 单回合流程

### 3.1 RoundWaiting

玩家进入回合等待阶段，系统确认参与者、加入策略、准备状态和地图目标。尚未具备参与资格的玩家保持观战或等待下一回合。

### 3.2 RoundPreparation

准备阶段示例时长为 20 秒，具体时长由模式调节。所有可参战玩家为人类，可以移动、观察地形、寻找防守点、检查武器和整理技能。

准备阶段的重点是建立空间优势：

- 人类寻找高低差、窄口、可封锁通道和撤退路线。
- 队伍决定火力覆盖、救援顺序和技能使用位置。
- 需要地图目标的变体在此阶段显示目标入口和阶段路线。
- 感染、回合胜负和僵尸出生选择在倒计时结束后才开始。

### 3.3 InitialInfection

倒计时结束后，系统按照玩家数量和模式配置计算初始僵尸数量，从合格的人类中随机选择初始感染者。

初始僵尸和母体僵尸可以拥有更高生命值、更强感染能力、专属技能、特殊移动能力或更高的成长起点。初始感染者的选择应让人类有明确的反应窗口，也让僵尸能在早期形成有效压力。

### 3.4 RoundActive

回合进入正式战斗。人类保护剩余队友并完成生存或逃亡目标，僵尸寻找目标并扩大感染范围。

此阶段持续处理：

- 普通攻击、技能攻击和特殊攻击。
- 感染尝试、感染抵抗、延迟感染和解除感染。
- 普通死亡、永久死亡、重生和观战。
- 最后一名人类、最终阶段、地图目标和胜负检查。
- 局内经验、成长、补给和技能升级。

### 3.5 RoundEnding

回合达到胜负条件后进入结算阶段。系统停止新的感染和战斗结算，展示回合结果、关键事件和局内奖励，清理回合专属状态，再进入下一回合或结束 Match。

## 4. 阵营与角色

阵营决定主要胜负目标，角色决定同一阵营中的能力、数值、感染方式和死亡规则。

| 阵营 | 角色 | 玩法定位 |
| --- | --- | --- |
| Human | 普通人类 | 使用武器和技能防守、撤退、救援并争取时间 |
| Human | 特殊人类 | 拥有抗感染、专属装备或特殊任务规则 |
| Human | 英雄或救世主 | 具备更高战斗上限，用于扭转感染压力 |
| Human | Hunter | 终结者变体中的特殊人类，专门追猎特殊僵尸 |
| Zombie | 普通僵尸 | 通过接近、攻击和感染扩大僵尸阵营 |
| Zombie | 初始僵尸 | 回合开局感染者，具有更强的早期能力 |
| Zombie | 母体或特殊僵尸 | 通过专属技能、范围能力和感染能力制造突破口 |
| Zombie | 进化僵尸 | 在感染、伤害、存活或愤怒积累后提升阶段 |

角色变更不只是模型和颜色变化。角色变更会同时影响生命值、护盾或护甲、移动能力、可用技能、攻击方式、感染能力、死亡规则和队伍目标。

## 5. 人类玩法

人类的核心目标是维持至少一名仍可参战的人类，直到时间结束、目标完成或所有僵尸失去继续作战的资格。

人类需要处理四种压力：

- 站位压力：高处和窄口有利于防守，但撤退路线有限。
- 火力压力：弹药、换弹、射界和队友间的交叉火力决定突破口能否被封住。
- 感染压力：靠近僵尸会增加被攻击和被包围的风险。
- 技能压力：治疗、护盾、控制、位移、扫描和爆发技能需要配合阶段使用。

人类的有效决策包括：

- 选择集中防守或分散寻找地图资源。
- 用控制和减速延长安全距离。
- 在队友即将被包围时提前留出救援路径。
- 为最后阶段保留高价值技能和特殊武器。
- 根据僵尸类型调整目标优先级。

## 6. 僵尸玩法

僵尸的核心目标是让人类数量降到胜利条件，或在逃亡变体中阻止人类抵达安全区。

僵尸的有效战斗循环包括：

1. 发现人类并确认接近路线。
2. 通过外围追击、夹击和封路迫使人类失去站位。
3. 使用普通攻击、特殊技能或范围能力制造感染机会。
4. 在人类阵型出现缺口时集中突破。
5. 通过感染数量、战斗表现或存活时间触发成长。

僵尸脱离战斗一段时间后可以恢复生命。恢复应与受击、控制和持续战斗状态关联，避免僵尸在交战中无限恢复，也避免短暂脱离后完全失去追击能力。

击退、硬直、减速和控制抗性属于僵尸类型的一部分。普通僵尸可以被持续控制，特殊僵尸通过抗性、位移或技能解除维持进攻节奏。

## 7. 感染规则

### 7.1 感染与死亡

伤害会消耗护盾、护甲或生命值，感染会改变玩家的阵营和角色。两者可以在同一次攻击中先后发生，但玩家必须能理解当前结果属于受伤、感染、死亡、重生还是永久淘汰。

普通人类被成功感染后继续参与本回合，玩家的目标从保护人类转为帮助僵尸扩大感染。感染可以通过替换形态、切换战斗配置或直接转换当前形态完成，玩家始终保留当前回合的参与资格，具体表现由模式规则决定。

### 7.2 感染策略

模式可以选择以下感染方式：

- 直接感染：满足攻击条件后直接清空当前生命值，并穿透当前护盾，随后立即转为僵尸。
- 生命归零感染：攻击先按普通伤害扣除护盾和生命值，生命归零时执行感染。
- 特殊人类生命归零：普通人类被感染，特殊人类按照特殊规则死亡或转化。
- 一次性抵抗：防化服或特殊技能完整抵挡一次感染攻击。该次攻击不造成伤害，也不恢复已经损失的生命值。抵抗资格消耗后，后续攻击按当前模式规则处理。
- 两次攻击感染：每次攻击按普通伤害结算，生命值经过两次有效命中后归零并感染。具体结果由伤害、护盾和生命值数值形成，不以独立命中计数改变规则。
- 延迟感染：目标进入待感染状态，在倒计时结束后转化。
- 解除感染：目标在延迟期间使用解毒剂、队友技能或地图设施恢复人类身份。

每种感染策略都应明确攻击条件、抵抗条件、待感染期间的行为、解除方式和最终转化结果。

### 7.3 感染状态

玩家可处于以下感染相关状态：

- 正常人类。
- 感染免疫。
- 待感染。
- 已成功感染。
- 受特殊感染效果影响。

感染状态需要影响外观、提示、技能、可交互目标和队伍判断，避免玩家只看到一个模型变化却无法理解规则。

## 8. 战斗、伤害与控制

### 8.1 普通战斗

武器和技能可以造成枪械、爆炸、近战、环境、弱点和持续伤害。爆头、近战终结、英雄技能和特殊武器可以触发区别于普通击杀的结果。

### 8.2 护甲、护盾与生命

护甲或护盾可以承担部分伤害，也可以提供一次感染抵抗。生命值归零后的结果由角色和模式决定，普通人类优先遵循感染规则，特殊角色优先遵循自己的死亡规则。

### 8.3 击退与硬直

击退改变空间位置，硬直打断当前攻击或追击，减速改变接敌节奏。僵尸类型可以拥有击退抗性、硬直抗性和减速抗性，特殊抗性应通过角色设计表达。

### 8.4 近战命中

近战攻击由可见的攻击动作和接触窗口组成。攻击动作进入命中窗口后，只有处于武器范围、攻击方向和有效目标范围内的对象受到伤害或感染。

## 9. 僵尸死亡与重生

不同模式使用不同的僵尸死亡策略。

### PermanentDeath

僵尸死亡后进入观战或永久淘汰。适合终结者、特殊僵尸和强调击杀价值的规则。

### RespawnUnlessSpecialKilled

普通僵尸死亡后等待一段时间重生，特殊僵尸被爆头、近战终结或英雄终结后永久淘汰。普通击杀控制僵尸数量，特殊击杀改变最终胜负压力。

### InfiniteRespawn

僵尸可以持续重生。僵尸数量归零不能直接宣布人类胜利，胜负改由时间、逃亡目标或地图任务决定。

以上三种死亡与重生方式都是模式规则。不同模式可以选择不同方式，并进一步设置重生时间、出生点、出生保护和特殊终结条件。

基础模式优先采用普通僵尸可重生、特殊僵尸按终结条件永久淘汰的目标规则，具体重生时间、出生点和特殊击杀条件由模式配置。

## 10. 胜负与最后人类

### 僵尸胜利

- 可参战人类数量为零。
- 逃亡变体中人类未能在规定时间抵达安全区。
- 地图目标要求人类保护的对象被摧毁。

### 人类胜利

- 计时结束时仍有可参战人类。
- 所有需要永久淘汰的僵尸均已失去继续作战资格。
- 人类完成逃亡、护送或其他地图目标。

### 最后一名人类

当人类数量降到配置阈值时，回合进入最后人类阶段。该事件可以触发：

- 新的计时或最终倒计时。
- 地图出口、补给箱或特殊武器开放。
- 人类临时增益或英雄规则。
- 僵尸强化、重生调整或最终决战入口。

最后人类阶段属于独立的玩法阶段，最终胜负由阶段规则继续决定。

## 11. 技能化与局内构筑

### 11.1 技能目标

技能是生化模式的核心战斗层。角色通过主动技能、被动技能、角色固有能力和特殊感染能力形成差异。感染过程会改变玩家的战斗角色，技能构筑需要参与这种变化。

### 11.2 四槽主动技能

玩家在一场 Match 中最多装备四个主动技能。技能通过拾取、回合奖励、三选一、商店、神秘商人、融合或变异获得，重复获得可以升级，目标上限为三级。

每个技能至少表达以下内容：

- 作用目标和适用阵营。
- 主动、被动或终极能力类型。
- 冷却和资源消耗。
- 等级成长。
- 对普通攻击、感染、救援、逃亡或生存阶段的影响。

### 11.3 感染时的技能变化

感染后，玩家获得僵尸角色能力，同时依据每个技能的适用阵营处理当前构筑。共享技能继续发挥作用，僵尸可用技能继续保留，人类专属技能转为对应的僵尸能力或暂时失效，技能等级和局内成长按技能条目规则处理。

感染不会把玩家的局内成长静默抹除。技能槽位和等级继续保留，转换结果按技能条目提前定义：

- 共享技能保持在原槽位，继续使用，当前冷却按原技能继续计算。
- 有 Zombie 对应能力的技能在原槽位替换为对应能力，保留技能等级和局内成长。
- 只有 Human 可用且没有 Zombie 对应能力的技能暂时停用，保留槽位、等级和获得记录，界面明确显示暂不可用。
- 人类专属的持续效果、正在执行的动作和只服务于人类武器或外观的能力在转换时结束。角色通用效果只有在技能规则明确允许时才保留。

角色转换同时改变阵营、角色目标、可用能力、战斗网格和动画表现。具体 Zombie 角色采用独立角色还是复用当前角色形态，由角色资产方案决定，不改变上述技能体验规则。

### 11.4 回合之间的技能

技能构筑属于一场 Match 的临时成长。回合结束清理回合状态，技能槽、技能等级和构筑是否保留由当前模式明确规定，基础目标为跨回合保留。

## 12. 玩法变体

### 12.1 终结者模式

开局选择一名强化特殊僵尸。普通僵尸持续感染和压制人类。人类数量降到阈值后，特殊人类转为 Hunter。

Hunter 的目标是追杀特殊僵尸。Hunter 使用生命值伤害和更高强度的武器、技能、生命值或移动能力。Hunter 被感染后可以转为僵尸，也可以按规则永久淘汰。特殊僵尸被普通枪械击杀后可以重生，被近战、爆头或英雄终结后永久淘汰。

Hunter 被感染或永久淘汰后，终结阶段继续按照剩余角色和时间决定胜负。

### 12.2 救世主或英雄模式

英雄保持人类身份，拥有专属武器、技能、生命值、移动能力或救援能力。英雄的存在提高人类反攻能力，但不能让普通人类失去生存和协作价值。

### 12.3 Human Morale

人类永久击杀特殊僵尸或完成关键目标后获得士气。士气可以提供伤害、移动、换弹、感染抵抗或救援效率增益，增益持续到回合结束。

### 12.4 Zombie Evolution

僵尸通过感染、造成伤害、存活时间、被击退次数或愤怒积累获得进化。进化可以改变生命值、伤害、移动能力、技能、抗性和外观，进化阶段示例为普通、进化、母体或精英。

### 12.5 生化 Z 与局内成长

启用后，玩家通过感染、击杀、目标、存活、救援和回合结果获得局内经验或生化 Z。等级可以解锁技能、被动、武器、角色或商店内容。

局内成长服务于当前 Match 的节奏，数值成长需要保持人类防守和僵尸扩散之间的可逆压力。

### 12.6 金币与商店

金币可以来自击杀、助攻、感染、目标、存活时间、救援、补给和回合奖励。商店可以出售武器、弹药、护甲、解毒剂、技能升级、特殊道具和角色强化。

商店购买与技能获得属于局内事务，购买时应明确价格、库存、刷新、购买限制和回合结束后的保留范围。

### 12.7 生化逃亡与生化追击

逃亡地图按阶段推进：

Start → A → B → C → EscapeZone

地图通过门、电梯、桥梁、检查点、可破坏物和触发区域控制阶段变化。玩家需要在战斗中推进目标，僵尸负责拖延、感染和阻断。

逃亡可以采用两种胜利方式：

- Team Escape：达到安全区的人类共同完成队伍逃亡。
- Individual Escape：每名抵达安全区的人类单独完成逃亡。

逃亡变体默认允许检查点或无限重生，具体重生点、重生时间和感染后的回场规则由地图阶段配置。

### 12.8 生化剑客与最终决战

最终决战可以由剩余玩家数量、剩余时间、目标完成、特殊角色存活或地图阶段触发。决战参与者、武器、技能限制、场地和胜利条件由决战规则决定。

最后一名人类只是常见触发条件，系统也可以使用其他组合条件。

### 12.9 补给箱

补给箱可以提供武器、弹药、治疗、护盾、护甲、解毒剂、技能升级、金币或特殊角色资源。补给箱可以在开局、阶段转换、最后人类或特殊事件中出现。

### 12.10 特殊感染

特殊感染可以使用延迟感染、范围感染、标记感染、链式感染、感染抗性削弱和解毒窗口等形式。特殊感染必须展示持续时间、触发条件、解除方式和转化结果。

## 13. 加入、退出与异常情况

### 中途加入

模式可以允许玩家：

- 观战并等待下一回合。
- 作为普通僵尸加入。
- 直接加入当前回合的人类或僵尸。
- 在当前 Match 禁止加入。

基础目标为初始感染完成后进入观战，下一回合再成为可参战玩家，保证初始随机和回合人口稳定。

### 玩家退出

玩家退出后从当前参与人口中移除，重新计算人类、僵尸、永久淘汰和胜负条件。退出事件不会制造额外感染，也不会重复触发死亡奖励。

### AFK 与自杀

AFK 可以触发标记、移交观战、限制奖励或自动退出。自杀使用独立死亡原因，按模式决定是否感染、是否计入击杀、是否触发特殊终结和是否允许重生。

## 14. 首要实现目标

第一阶段先完成一条可完整游玩的基础感染回合：

1. 多人进入同一场 Match。
2. 准备阶段结束后随机产生初始僵尸。
3. 人类和僵尸拥有清晰的角色能力。
4. 普通人类可以被感染并继续参与。
5. 普通僵尸和特殊僵尸拥有可配置的死亡与重生规则。
6. 四槽局内技能可以获得、升级、释放和清理。
7. 最后一名人类事件能够触发最终阶段。
8. 人类和僵尸能够按规则结束回合并进入下一回合。

终结者、英雄、士气、进化、局内等级、经济、商店、逃亡、最终决战、补给箱和特殊感染作为可组合变体逐项加入。每个变体沿用基础感染、回合和技能生命周期。

## 15. 玩家验收标准

- 玩家能看懂当前回合阶段、剩余时间、双方人数和自己的阵营角色。
- 人类知道防守目标、撤退方向、感染风险和可用技能。
- 僵尸知道目标、感染机会、重生状态和自身能力。
- 普通人类被感染后仍能继续操作，并能立即理解自己的新目标。
- 普通伤害、感染、死亡、永久淘汰和重生在表现和结果上清晰区分。
- 最后一名人类阶段会改变节奏，并提供明确的决战或逃亡目标。
- 技能获得、升级、冷却、角色适用范围和感染后的变化有一致反馈。
- 回合结束后的清理和下一回合准备不会留下上一回合的错误阵营、生命值、技能状态或地图目标。
