# GameDesign 摘要：材料与制作（来源：Docs/SystemDesign/GameDesign/游戏设计完整文档 v7.0 Final.md §7.3-7.4）

## 材料类型
- 军用合金：传说武器与稀有服装的核心消耗品（50/把、10/套），Boss100%掉落，存储上限999。
- 势力徽章（5种）：Chapter任务一次性获取，制作对应势力武器/服装的前置条件，不可堆叠。
- 传说武器设计图（5张）：章节/支线/探索奖励，解锁对应武器配方，仅1张/种。
- 服装碎片：常见材料，100碎片=1套普通服，200+材料+徽章=稀有服装，可堆叠9999。
- 金币：多来源数值货币，用于商店、制作费用（5000/把）与急救采购材料，上限99999。

## 材料管理与背包
- 材料栏与武器/消耗品隔离，自动拾取、自动堆叠、无重量限制。
- Tab→背包→材料标签展示所有材料及数量。
- 掉落视觉：不同稀有度对应橙/紫/金/蓝/黄光柱，拾取时在屏幕右上角提示“+2 军用合金”。

## 制作系统（Hub 仓库 · 军械师老赵）
- UI 左侧为5把传说武器卡片，右侧为详情与制作条件（徽章、设计图、材料、金币）绿色勾/红叉标识。
- 满足条件启用绿色“制作”按钮，触发3秒锻造动画；制作完成后消耗材料并把武器放入背包，同时触发成就或提示。
- 服装制作同流程，分普通/稀有/传说类别。
- 所有传说武器配方：对应势力徽章×1 + 对应设计图×1 + 军用合金×50 + 金币×5000。

## 系统交互
- 材料掉落与副本评级关联（S/A/B/C影响倍率），随机事件与隐藏房间掉落稀有材料。
- 游戏强调“已拾取物品不重置”避免刷材料，背包需记录持久状态并与章节进度同步。
- 传说武器制作完成后需更新成就与 NPC 对话分支。
