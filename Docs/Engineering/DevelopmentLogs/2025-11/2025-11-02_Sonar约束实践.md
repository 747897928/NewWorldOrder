# Sonar代码质量约束实践

日期：2025-11-02
负责人：AI
状态：已完成

## 背景

新导入的GA/武器逻辑集中在AbilitySystem/Abilities与Weapons目录，若单函数过长或嵌套过深会违反Sonar维护性硬约束。

## 约束要求

Sonar硬约束：
- 函数行数 <= 80
- 嵌套层级 <= 3
- 认知复杂度 <= 15

## 问题分析

潜在超标函数：
- AShootProjectileBase::ApplyRadialDamage（爆炸伤害计算）
- 包含伤害衰减、物理材质查询、弱点倍率计算
- 逻辑复杂，容易超出行数限制

## 重构方案

拆分原则：
- 主流程函数保持清晰的逻辑主线
- 提取计算逻辑到辅助函数
- 使用提前返回减少嵌套

重构前：
```cpp
void AShootProjectileBase::ApplyRadialDamage(...)
{
    // 100+行的复杂逻辑
    // 嵌套4层
}
```

重构后：
```cpp
void AShootProjectileBase::ApplyRadialDamage(...)
{
    // 主流程54行
    // 调用辅助函数
    float Damage = CalculateExplosiveDamage(...);
    UPhysicalMaterial* PhysMat = ResolvePhysicalMaterial(...);
    // ...
}

float AShootProjectileBase::CalculateExplosiveDamage(...)
{
    // 伤害计算逻辑
    // 提前返回
    if (Distance > OuterRadius) return 0.0f;
    // ...
}

UPhysicalMaterial* AShootProjectileBase::ResolvePhysicalMaterial(...)
{
    // 物理材质查询逻辑
    if (!HitResult.IsValidBlockingHit()) return nullptr;
    // ...
}
```

## 实施结果

检查结果：
- 使用temp_sonar.py脚本扫描AbilitySystem/Abilities和Weapons目录
- 所有函数确认无超出80行
- AShootProjectileBase::ApplyRadialDamage拆分后主函数54行

## 代码规范

函数编写准则：
1. 单一职责：一个函数只做一件事
2. 提前返回：减少嵌套层级
3. 提取辅助函数：复杂计算独立出来
4. 保持主流程清晰：逻辑主线一目了然

示例模式：
```cpp
void MainFunction()
{
    // 验证参数
    if (!IsValid(...)) return;

    // 第一步
    Data1 = HelperFunction1(...);
    if (!Data1) return;

    // 第二步
    Data2 = HelperFunction2(...);

    // 第三步
    FinalStep(Data1, Data2);
}
```

## 检测工具

临时脚本temp_sonar.py：
```python

# 执行完删除，避免污染仓库
```

使用方式：
