## 第一章：游戏概述

### 1.1 核心定位

**游戏名称**: 新秩序（New Order）

**核心玩法**:

- 第三人称合作射击（TPS）
- 双主角叙事驱动
- RPG成长系统
- 线性剧情副本 + 随机事件

**灵感来源**:

- 《求生之路2》（L4D2）- 合作射击基础
- 《Back 4 Blood》（B4B）- RPG成长系统
- 《刺客信条：枭雄/影》- 双主角切换机制
- 《Warhammer 40K: Darktide》- GAS技术架构
- 《无畏契约》 - 键位
- 《守望先锋》 - 武器和技能设计思路
- 《致命解药》The Killing Antidote - UI和交互
- 《双人成行/双影奇景》- 本地双人同屏

**目标玩家**:

- L4D2/B4B老玩家
- 喜欢合作射击的玩家
- 女性玩家友好（参考无畏契约）
- 情侣（下班回家后可以一起在沙发大屏幕上玩本地分屏，一个人操作男主角，一个人操作女主角）
- 死党，好基友。
- 学生群体。

**核心卖点**:

1. 双主角剧情（90万字世界观支撑）
2. 丰富的RPG成长（属性/技能/装备）
3. 随机事件系统（每次通关都不同）
4. 传说武器（特殊机制，配合Build）
5. 本地/在线合作（最多4人）

### 1.2 游戏世界观（简述）

**背景**: 一个退役特种兵，一个末世幸存者，一组分散的疫苗数据，在丧尸末世中搅动三大势力，建立平等的新火。

**主角**:

- **陈浩宇（男）**: 
  - 身份：前龙旗特种兵，现独立佣兵
  - 年龄：30岁
  - 外貌：精悍，锐利，军人气质
  - **性格核心**：
    - 可靠：战友最信任的人
    - 成熟稳重：基于战术分析决策
    - 有底线：拒绝伤害无辜
    - 低调务实：不出风头
    - 谨慎：不主动碰烫手山芋
    - 有理想主义的一面：相信"拯救人类"的理念
- **沈芸皖（女）**: 
  - 身份：末世幸存者，医生助手
  - 年龄：23岁（爆发时20岁）
  - 外貌：清秀温柔，笑容温暖
  - **性格核心**：
    - 活泼开朗：日常爱说笑，能调节气氛
    - 温柔善良：对伤员和孩子很耐心
    - 有底线：涉及原则问题绝不退让
    - 坚韧：经历创伤仍保持乐观

**五大势力**:

1. 龙旗（东方秩序集团）
2. 联邦临时政府-北方军区（西方军事联盟）
3. 自由民团（平民自治组织）
4. 潜影商行（地下交易网络）
5. 复兴集团（技术垄断资本）

### 1.3 设计理念

**射击占80%，技能占20%**:

- 技能是倍增器，不是替代品
- 15-30秒CD保持战术性
- 强调枪法和走位

**合作是锦上添花，不是雪中送炭**:

- 单人可以通关（简单/普通难度）
- 双人更轻松
- 4人体验最佳（困难/噩梦难度）

**双主角差异化**:

- 男主：坦克前排（高血量+触发护盾+近战技能）
- 女主：机动辅助（高移速+救援+治疗）
- 单人模式在Hub切换角色（参考刺客信条）
- 多人模式可选任意组合

## 第二章：游戏框架

### 2.1 游戏模式

#### 模式1：单人模式

```
玩家控制：1个主角（男主或女主）
本地玩家数量：1
角色切换：仅在Hub中切换（参考刺客信条枭雄/影）
不可在副本战斗中切换
敌人数量：×1.0（基础）
```

#### 模式2：本地分屏（2玩家）

```
玩家A：控制男主
玩家B：控制女主
屏幕分割：竖直分屏（参考双人成行）
本地玩家数量：2
敌人数量：×1.5（不是×2）
共享进度：所有奖励和解锁共享
```

#### 模式3：在线合作（最多4玩家）

```
网络架构：Listen Server（无专用服务器）
角色选择：可以2男2女，或任意组合
敌人数值：动态调整（见难度系统）
本地玩家数量：1(无分屏，1个主角（男主或女主）)
Steam P2P：网络通信
```

注意：男主和女主的背包预设是不一样的。比如男主的背包预设是AK47,手枪1,近战武器1。女主的背包预设可能是狙击枪1，手枪2，近战武器2。

### 2.2 难度系统

| 难度 | 敌人血量 | 敌人伤害 | 敌人数量 | 推荐      | 词缀    | 奖励倍率 |
| ---- | -------- | -------- | -------- | --------- | ------- | -------- |
| 简单 | ×0.7     | ×0.8     | -30%     | 新手/休闲 | 无      | ×0.8     |
| 普通 | ×1.0     | ×1.0     | 100%     | 单人可过  | 无      | ×1.0     |
| 困难 | ×1.3     | ×1.2     | +30%     | 推荐2-3人 | 无      | ×1.5     |
| 噩梦 | ×2.0     | ×1.5     | +100%    | 强制4人   | 随机3个 | ×2.0     |

**人数动态调整（所有难度）**:

```
1人：基础数值
2人：敌人血量×1.3，数量×1.5
3人：敌人血量×1.6，数量×2.0
4人：敌人血量×2.0，数量×2.5

技术实现：
- 玩家加入/离开时，GameMode移除旧的缩放GE
- 重新应用对应人数的缩放GE到所有AEnemyBotCharacter的ASC
- 精英敌人额外缩放（2人×1.3，3人×1.6，4人×2.0）
```

### 2.3 噩梦难度词缀系统

**触发规则**:

- 仅噩梦难度生效
- 每次进入副本随机抽取3个词缀
- 词缀从10个词缀池中抽取，不重复

**词缀列表**:

| 词缀名   | 效果                             | 难度评级 |
| -------- | -------------------------------- | -------- |
| 狂暴     | 敌人移速+30%，攻速+50%           | ★★★      |
| 装甲     | 所有敌人护甲+50                  | ★★★★     |
| 元素     | 敌人死亡爆炸（2米范围，50伤害）  | ★★       |
| 精英潮   | 精英数量×2                       | ★★★★★    |
| 腐蚀     | 玩家每秒流失2% MaxHP             | ★★★      |
| 弹药危机 | 弹药掉落-80%                     | ★★★★     |
| 雾隐     | 敌人隐身直到5米内                | ★★★      |
| 坚韧     | 敌人受到控制效果-50%             | ★★       |
| 玻璃大炮 | 敌人伤害+50%，血量-30%           | ★★       |
| 混乱标记 | 战术标记持续时间-50%，技能CD+20% | ★★★      |

**奖励加成**:

```
基础奖励：经验×2，材料×2
词缀难度评级相加越高获得稀有道具概率越高
额外：传说武器设计图掉落率大幅提升
专属：噩梦专属服装解锁
```

**UI显示**:

```
进入副本前：显示本次3个词缀的详细说明
副本中：左上角显示词缀图标（鼠标悬停查看说明）
需要考虑手柄玩家如何查看说明
```

### 2.4 游戏规模

**通关时长**: 15-20小时

- 主线12章：16小时
- 支线任务：2小时
- 隐藏挑战：2小时

**章节数量**: 12章（固定）

**章节结构**:

```
Chapter 1-3：教学关（3小时）
  - 系统教学
  - 剧情铺垫
  - 普通难度友好

Chapter 4-6：剧情展开（4小时）
  - 五大势力登场
  - 传说武器获取开始
  - 随机事件引入

Chapter 7-9：剧情高潮（5小时）
  - 真相揭露
  - 大量Boss战
  - 困难难度推荐

Chapter 10-12：终章（4小时）
  - 最终决战
  - 多结局分支
  - 噩梦难度挑战
```

**每章时长**: 60-90分钟（平均75分钟）

**副本大小**: 0.8-1.5km²

### 2.5 操作键位

**移动与基础操作**:

```
W/A/S/D：前进/左移/后退/右移
Space：跳跃
左Ctrl：下蹲（减少脚步声，降低后坐力）
左Shift：静步移动（大幅降低脚步声）
F键：翻滚（充能系统，最多3次）
```

**武器与射击**:

```
鼠标左键：射击
鼠标右键：瞄准（ADS）
R键：换弹
1/2/3键：切换主武器/副武器/近战武器
G键：丢弃当前武器
```

**技能释放**（参考无畏契约）:

```
Q键：小技能1（15-20秒CD）
E键：小技能2+交互/拾取（20-30秒CD）
C键：小技能3（18-20秒CD）
X键：大招（充能100点）
```

**消耗品**（参考L4D2）:

```
4键：投掷道具（手雷/燃烧瓶/闪光弹等）
  - 同时只能持有1个
  - 拾取新的会替换旧的
  - 使用后槽位变空

5键：医疗道具（医疗包/止痛药/肾上腺素）
  - 同时只能持有1个
  - 拾取新的会替换旧的
  - 使用后槽位变空
```

**UI提示**:

```
E键提示：交互/拾取（白色）
F键提示：翻滚可用次数（3/3）
4键提示：当前投掷道具图标
5键提示：当前医疗道具图标
```

### 3.2 属性系统

#### 等级与属性点

**等级范围**: 1-30级

**属性点获取**:

```
Lv1: 
  男主4点固定（力量2, 体力2, 敏捷0, 感知0）
  女主4点固定（力量0, 体力1, 敏捷2, 感知1）
     
Lv2-29: 每级+2点自由分配（56点）

Lv30: 全属性+3（力量+3, 体力+3, 敏捷+3, 感知+3）（12点）

总计: 72点（4初始 + 56自由 + 12满级）
```

**满级属性示例**:

```
男主DPS流: 力30、体7、敏10、感25
男主坦克流: 力25、体30、敏8、感9
女主机动流: 力15、体7、敏30、感20
女主辅助流: 力17、体20、敏20、感15
```

#### 体力（Vitality）

**效果1：最大生命值（三段递减）**

```
公式: MaxHP = BaseHP + VitalityBonus

BaseHP = 100

VitalityBonus计算:
- 0-10点: 每点+12 HP
- 11-20点: 每点+8 HP  
- 21-30点: 每点+6 HP

总计: 100 + 260 = 360 HP（基础）
```

**关键数值点**:

```
0点: 100 HP
10点: 220 HP
20点: 300 HP
30点: 360 HP

男主（+15%）: 360 × 1.15 = 414 HP
女主（-10%）: 360 × 0.9 = 324 HP
```

**实战参考**（Chapter 10噩梦难度）:

```
游荡者: ~30伤害/击
414 HP = 13.8次攻击
324 HP = 10.8次攻击

猎手: ~50伤害/击
414 HP = 8.3次攻击
324 HP = 6.5次攻击
```

**效果2：护盾容量上限**

```
公式: ShieldCapacity = (20% + Vitality × 1%) × MaxHP

30点体力男主:
- MaxHP: 414
- 护盾上限: 414 × 0.5 = 207

护盾规则:
- 护盾默认不存在（技能提供）
- 护盾破碎后15秒CD
- 未破碎时，脱战5秒后开始恢复（每秒10%容量）
```

**效果3：减伤**

```
公式: DamageReduction = Vitality × 0.2%

30点体力: 6%减伤

配合生存大师Lv3（低血<40%时）:
总减伤: 6% + 35% = 41%减伤
```

#### 力量（Strength）

**效果1：武器伤害加成（三段递减）**

```
公式: DamageBonus计算

- 0-15点: 每点+2%（0-30%）
- 16-25点: 每点+1.5%（30-45%）
- 26-30点: 每点+1%（45-50%）

最终伤害 = BaseDamage × (1 + DamageBonus)
```

**关键数值点**:

```
0点: +0%伤害
15点: +30%伤害
25点: +45%伤害
30点: +50%伤害
```

**示例（AK47基础35伤害）**:

```
0点力量: 35伤害
15点力量: 35 × 1.3 = 45.5伤害
30点力量: 35 × 1.5 = 52.5伤害
```

**效果2：护甲穿透**

```
公式: ArmorPenetration = Strength × 0.8%

30点力量: 24%穿透

示例:
敌人护甲50点
有效护甲 = 50 × (1 - 0.24) = 38点
```

#### 敏捷（Agility）

**效果1：移速加成（三段递减）**

```
公式: MoveSpeedBonus计算

- 0-15点: 每点+1%（0-15%）
- 16-25点: 每点+0.75%（15-22.5%）
- 26-30点: 每点+0.5%（22.5-25%）

最终移速 = BaseMoveSpeed × (1 + MoveSpeedBonus) × CharacterMultiplier
```

**关键数值点**:

```
0点: 100%移速
15点: 115%移速
25点: 122.5%移速
30点: 125%移速

男主（-5%）: 125% × 0.95 = 118.75%移速
女主（+15%）: 125% × 1.15 = 143.75%移速
```

**效果2：射击移速惩罚减免**

```
基础规则: 所有角色射击时移速-40%

公式: 惩罚减免 = Agility × 1%

30点敏捷: 射击时移速-10%（而非-40%）

女主额外加成: 射击时移速惩罚再-5%
30点敏捷女主射击: 移速-5%
实际移速: 143.75% × 0.95 = 136.56%
```

**效果3：换弹速度**

```
公式: ReloadSpeedBonus = Agility × 1.5%

最终换弹时间 = BaseReloadTime × (1 - ReloadSpeedBonus)

30点敏捷: 换弹时间×55%（-45%）

示例（AK47基础2.2秒）:
- 0点敏捷: 2.2秒
- 15点敏捷: 2.2 × 0.775 = 1.705秒
- 30点敏捷: 2.2 × 0.55 = 1.21秒

配合速射手Lv3（-30%）:
总换弹时间: 2.2 × 0.55 × 0.7 = 0.847秒
```

**效果4：翻滚充能系统（简化）**

```
基础规则:
- 最大充能: 3次（固定）, 默认只有1层充能上限，需要加点敏捷到一定等级后才能解锁充能上限
- 充能时间: 10秒/次（固定，不受敏捷影响）
- 翻滚距离: 5米
- 按键: F键

简化递减机制（仅距离递减）:

第1次翻滚（计数=0）:
- 无敌时间: 0.4秒
- 翻滚距离: 5米

第2次翻滚（计数=1，5秒内）:
- 无敌时间: 0.4秒（保持不变）
- 翻滚距离: 4米（-20%）

第3次翻滚（计数=2，5秒内）:
- 无敌时间: 0.4秒（保持不变）
- 翻滚距离: 3米（-40%）

惩罚重置: 8秒未使用翻滚，重置计数

设计理念:
- 玩家只需记住"翻太多距离变短"
- 无敌时间固定，保持防御能力
- 无移速惩罚，避免过度惩罚
```

#### 感知（Perception）

**效果1：弱点伤害倍率**

```
公式: HeadshotMultiplier = BaseMultiplier + (Perception × 1.5%)

BaseMultiplier:
- 步枪/霰弹枪/冲锋枪: 2.0（200%）
- 狙击枪专属: 2.5（250%）

30点感知:
- 步枪爆头: 2.0 + 0.45 = 2.45倍
- 狙击枪爆头: 2.5 + 0.45 = 2.95倍
```

**示例（AK47，30点力量+30点感知）**:

```
身体命中: 35 × 1.5 = 52.5伤害
爆头命中: 52.5 × 2.45 = 128.625伤害
```

**效果2：暴击率**

```
公式: CriticalChance = Perception × 0.75%

30点感知: 22.5%暴击率（对无抗性敌人）

暴击机制:
- 暴击判定独立于命中部位（爆头和身体都可触发暴击）
- 爆头和暴击是两个独立的伤害乘区，可以同时生效
- 暴击倍率: 1.5倍（基础）

暴击抗性机制:
- 精英和Boss拥有暴击抗性，会降低实际暴击触发率
- 实际暴击率 = 基础暴击率 × (1 - 暴击抗性%)
- 重要: 爆头伤害不受暴击抗性影响！

实际暴击率示例（30点感知）:
- 对普通敌人（0%抗性）: 22.5%
- 对吞噬者（30%抗性）: 22.5% × (1 - 0.3) = 15.75%
- 对装甲丧尸（50%抗性）: 22.5% × (1 - 0.5) = 11.25%
- 对Boss（70%抗性）: 22.5% × (1 - 0.7) = 6.75%

设计理念:
- 普通敌人无暴击抗性，保证感知流日常清怪体验
- 精英和Boss有抗性，强制感知流玩家提升爆头技术
- 爆头不受抗性影响，技术永远有价值

伤害类型详解:

所有命中都会独立判定暴击，形成4种伤害类型:

1. 爆头暴击（最高伤害）:
   - 计算: 基础伤害 × 爆头倍率 × 暴击倍率
   - 示例（30感知）: 伤害 × 2.45 × 1.5 = 3.675倍
   - 触发方式: 爆头命中 + 暴击判定成功
   - 触发概率（vs普通敌人）: 爆头率 × 22.5%
   - 触发概率（vs Boss）: 爆头率 × 6.75%（暴击抗性削弱）
   - 视觉: 红色（爆头）+ 金色闪光（暴击）
   - 音效: 爆头音效 + 暴击音效叠加

2. 爆头普通:
   - 计算: 基础伤害 × 爆头倍率
   - 示例（30感知）: 伤害 × 2.45
   - 触发方式: 爆头命中 + 暴击判定失败
   - 触发概率（vs普通敌人）: 爆头率 × 77.5%
   - 视觉: 红色伤害数字
   - 音效: 爆头音效

3. 身体暴击:
   - 计算: 基础伤害 × 暴击倍率
   - 示例: 伤害 × 1.5
   - 触发方式: 身体命中 + 暴击判定成功
   - 触发概率（vs普通敌人）: 身体命中率 × 22.5%
   - 视觉: 黄色伤害数字
   - 音效: 暴击音效

4. 身体普通:
   - 计算: 基础伤害 × 1.0
   - 触发方式: 身体命中 + 暴击判定失败
   - 视觉: 白色伤害数字
   - 音效: 普通命中音效

期望伤害分析（30感知，假设50%爆头率）:

对普通敌人（0%暴击抗性）:
- 爆头暴击（11.25%）: 3.675倍
- 爆头普通（38.75%）: 2.45倍
- 身体暴击（11.25%）: 1.5倍
- 身体普通（38.75%）: 1.0倍
- 期望伤害: 1.92倍

对Boss（70%暴击抗性）:
- 爆头暴击（3.375%）: 3.675倍
- 爆头普通（46.625%）: 2.45倍
- 身体暴击（3.375%）: 1.5倍
- 身体普通（46.625%）: 1.0倍
- 期望伤害: 1.86倍

关键结论:
- 暴击抗性主要削弱"爆头暴击"和"身体暴击"的触发率
- 爆头的基础倍率（2.45）不受暴击抗性影响
- 高爆头率玩家受暴击抗性影响较小（主要靠爆头基础倍率）
- 低爆头率玩家受暴击抗性影响较大（依赖身体暴击）

暴击视觉:
- 暴击: 黄色伤害数字 + 特殊音效
- 爆头: 红色伤害数字 + 爆头音效
```

**伤害示例（AK47，30点力量+30点感知）**:

```
对普通敌人（无护甲，无暴击抗性）:
身体命中: 52.5伤害
身体暴击（22.5%概率）: 52.5 × 1.5 = 78.8伤害
爆头普通: 52.5 × 2.45 = 128.6伤害
爆头暴击（22.5%概率）: 52.5 × 3.675 = 193伤害

对装甲丧尸（100护甲，50%暴击抗性）:
护甲计算: 有效护甲 = 100 × (1 - 0.24) = 76，减伤43%，造成57%伤害
身体命中: 52.5 × 0.57 = 29.9伤害
身体暴击（11.25%概率）: 78.8 × 0.57 = 44.9伤害
爆头普通（88.75%概率）: 128.6 × 0.57 = 73.3伤害
爆头暴击（11.25%概率）: 193 × 0.57 = 110伤害

结论:
- 力量的护甲穿透提升了14%实际伤害（50%→57%）
- 暴击抗性将暴击率降低了一半（22.5%→11.25%）
- 爆头暴击是最高伤害（110），但触发率低（11.25%）
- 爆头普通是稳定输出（73.3），触发率高（88.75%）
- 爆头期望伤害：73.3 × 0.8875 + 110 × 0.1125 = 77.5伤害

配合标记+易伤（对普通敌人）:
- 爆头基础: 128.6
- 标记×1.25: 128.6 × 1.25 = 160.8
- 易伤×1.30: 160.8 × 1.30 = 209伤害
```

### 武器拥有与双主角装备规则

- 武器解锁为**存档级共享**（账号级）：玩家在 HUB 通过商店购买、战利品掉落或合成制作取得一把武器后，该武器类型加入本存档的武器池。双主角（陈浩宇 / 沈芸皖）共享同一武器池，只要仓库中拥有该武器，两位主角都可在各自的 Loadout/QuickBar 中装备；未来新增可操控角色也沿用“解锁共享”规则。
- 装备携带与 QuickBar 配置为**角色级独立**：男主与女主各自拥有独立的装备栏与 QuickBar（主武器、副武器、近战、投掷物/技能道具等），修改一方不会同步到另一方。
- QuickBar 修改时机与限制：仅允许在 HUB 场景或主菜单/存档准备界面修改；关卡/副本内禁止打开仓库自由更换。HUB 中可卸下、选取已解锁武器并调整槽位顺序；变更会保存为该角色当前存档的默认 Loadout，并在双主角切换时恢复各自上次的装备状态。
- 双主角切换与装备：在 HUB/安全点可切换男女主，切换时保存当前主角 QuickBar/外观并加载目标主角的配置；切换不影响存档级武器池，只有“带哪些武器上场”发生变化。

#### 扩散系统

**扩散机制**:
```
当前扩散 = 基础扩散 + (射击次数 × 扩散增长)
当前扩散 = Min(当前扩散, 最大扩散)

停火后扩散恢复:
当前扩散 -= 扩散恢复速度 × DeltaTime

子弹偏移:
随机角度 = Random(-当前扩散, +当前扩散)
```

**不同武器的扩散特性**:
```

MAC-11（高扩散）:
- 基础2.5度，增长1.5度/发
- 适合近距离泼洒弹幕
```

**技术实现思路**:
```
在AHitscanWeaponInstance中:
- CurrentSpread: 当前扩散值（float）
- LastFireTime: 上次开火时间

射击时:
- AddSpread(): 增加扩散
- UpdateFiringTime(): 更新开火时间

Tick中:
- 检测停火时间 > 0.1秒
- 每帧恢复扩散: CurrentSpread -= SpreadRecovery × DeltaTime
```

### 5.5 护甲与抗性系统

#### 5.5.1 护甲机制

护甲是敌人的专属防御属性，玩家护甲始终为0。

**护甲减伤公式**:
```
有效护甲 = 护甲值 × (1 - 护甲穿透%)
减伤% = 有效护甲 / (有效护甲 + 100)
最终伤害 = 基础伤害 × (1 - 减伤%)
```

**计算示例（装甲丧尸，护甲100）**:

玩家A（0点力量，0%穿透）:
```
有效护甲 = 100 × (1 - 0) = 100
减伤% = 100 / 200 = 50%
造成伤害 = 100 × 0.5 = 50伤害
```

玩家B（30点力量，24%穿透）:
```
有效护甲 = 100 × (1 - 0.24) = 76
减伤% = 76 / 176 = 43.18%
造成伤害 = 100 × 0.5682 = 56.82伤害
提升比例 = 56.82 / 50 = 1.1364 = +13.64%
```

结论: 24%穿透降低了约7%的减伤值，提升了约14%的实际伤害。

**护甲值与减伤对照表**:

| 护甲值 | 0%穿透减伤 | 12%穿透减伤 | 24%穿透减伤 | 敌人类型 |
|--------|-----------|------------|------------|---------|
| 0 | 0% | 0% | 0% | 游荡者、猎手、尖啸者 |
| 5 | 4.76% | 4.25% | 3.80% | 潜伏者 |
| 10 | 9.09% | 8.21% | 7.39% | 爬行者 |
| 30 | 23.08% | 21.43% | 19.83% | 吞噬者 |
| 50 | 33.33% | 31.43% | 29.59% | 高护甲精英 |
| 100 | 50.00% | 46.81% | 43.18% | 装甲丧尸 |

**护甲设计理念**:
```
普通敌人低护甲或无护甲（0-10），穿透收益小
精英敌人中等护甲（30），穿透开始显现价值
特殊坦克高护甲（100），穿透收益最大化
力量Build在对抗高护甲敌人时有显著优势
```

#### 5.5.2 暴击抗性机制

暴击抗性是精英和Boss的专属属性，普通敌人暴击抗性为0。

**暴击抗性公式**:
```
实际暴击率 = 基础暴击率 × (1 - 暴击抗性%)
```

**计算示例（Boss，暴击抗性70%）**:

玩家（30点感知，22.5%基础暴击率）:
```
实际暴击率 = 22.5% × (1 - 0.7) = 6.75%
```

**期望伤害计算**:
```
期望伤害 = (1 - 暴击率) × 1.0 + 暴击率 × 1.2

对普通敌人（22.5%暴击率）:
期望 = 0.775 × 1.0 + 0.225 × 1.2 = 1.045 = 104.5%

对Boss（6.75%暴击率）:
期望 = 0.9325 × 1.0 + 0.0675 × 1.2 = 1.0135 = 101.35%

期望伤害降低: 104.5% → 101.35% = -3.15%
```

**暴击抗性对照表**:

| 敌人类型 | 暴击抗性 | 实际暴击率（22.5%基础） | 期望伤害 | 说明 |
|---------|---------|----------------------|---------|------|
| 普通敌人 | 0% | 22.5% | 104.5% | 无削弱 |
| 吞噬者 | 30% | 15.75% | 103.15% | 轻微削弱 |
| 装甲丧尸 | 50% | 11.25% | 102.25% | 中等削弱 |
| Boss | 70% | 6.75% | 101.35% | 大幅削弱 |

**重要说明**:
```
爆头命中不受暴击抗性影响
爆头自动视为暴击，但使用爆头倍率（2.45）而非暴击倍率（1.2）
暴击抗性只影响身体命中的暴击触发概率
玩家的暴击抗性始终为0（敌人不会对玩家暴击）
```

**暴击抗性设计理念**:
```
普通敌人无抗性，保证感知流日常清怪体验
精英敌人轻微抗性，降低身体暴击收益
Boss高抗性，强制感知流玩家依靠爆头技术
技术性爆头永远有价值（不受抗性影响）
```

#### 5.5.3 完整伤害计算流程

**最终伤害计算步骤**:

步骤1: 计算基础伤害
```
BaseDamage = 武器基础伤害
```

步骤2: 应用力量加成
```
Damage = BaseDamage × DamageMultiplier
DamageMultiplier = 1.0 + (力量加成%)
```

步骤3: 应用爆头倍率（如果爆头命中）
```
If 爆头命中:
    Damage = Damage × HeadshotMultiplier (2.45 for 30感知)
    // 爆头倍率不受暴击抗性影响
```

步骤4: 应用暴击倍率（独立判定）
```
实际暴击率 = 基础暴击率 × (1 - 敌人暴击抗性%)
触发判定 = 随机数Roll (0-1之间)
If 触发判定 < 实际暴击率:
    Damage = Damage × CriticalMultiplier (1.5)
// 注意: 无论是否爆头，都会进行暴击判定
// 爆头暴击 = 爆头倍率 × 暴击倍率 = 2.45 × 1.5 = 3.675
```

步骤5: 应用护甲减免
```
有效护甲 = 敌人护甲 × (1 - 玩家护甲穿透%)
减伤% = 有效护甲 / (有效护甲 + 100)
FinalDamage = Damage × (1 - 减伤%)
```

**完整伤害示例**:

武器: AK47，35基础伤害
玩家: 30力量（+50%伤害，24%穿透），30感知（2.45爆头倍率，22.5%暴击率）
敌人: 装甲丧尸，100护甲，50%暴击抗性

暴击判定前置说明:
- 实际暴击率 = 22.5% × (1 - 0.5) = 11.25%
- 每次命中都会Roll随机数判定是否暴击
- 爆头和身体命中都可能触发暴击

情况A: 爆头暴击（触发概率11.25%，假设爆头100%）
```
Step1: BaseDamage = 35
Step2: 35 × 1.5 = 52.5 (力量加成)
Step3: 52.5 × 2.45 = 128.6 (爆头倍率)
Step4: 128.6 × 1.5 = 193 (暴击倍率，Roll成功)
Step5: 有效护甲 = 100 × 0.76 = 76
       减伤 = 76 / 176 = 43.18%
       193 × 0.5682 = 110伤害
```

情况B: 爆头普通（触发概率88.75%，假设爆头100%）
```
Step1: BaseDamage = 35
Step2: 35 × 1.5 = 52.5
Step3: 52.5 × 2.45 = 128.6 (爆头倍率)
Step4: 128.6 × 1.0 = 128.6 (暴击Roll失败)
Step5: 128.6 × 0.5682 = 73.1伤害
```

情况C: 身体暴击（触发概率11.25%，假设身体命中）
```
Step1: BaseDamage = 35
Step2: 35 × 1.5 = 52.5
Step3: 52.5 × 1.0 = 52.5 (无爆头)
Step4: 52.5 × 1.5 = 78.8 (暴击Roll成功)
Step5: 78.8 × 0.5682 = 44.8伤害
```

情况D: 身体普通（触发概率88.75%，假设身体命中）
```
Step1: BaseDamage = 35
Step2: 35 × 1.5 = 52.5
Step3: 52.5 × 1.0 = 52.5 (无爆头)
Step4: 52.5 × 1.0 = 52.5 (暴击Roll失败)
Step5: 52.5 × 0.5682 = 29.8伤害
```

**伤害对比分析**:
```
期望伤害分析（假设100%爆头率）:
爆头期望 = 110 × 0.1125 + 73.1 × 0.8875 = 77.5伤害

期望伤害分析（假设50%爆头率）:
综合期望 = (110 × 0.1125 + 73.1 × 0.8875) × 0.5 + (44.8 × 0.1125 + 29.8 × 0.8875) × 0.5
         = 77.5 × 0.5 + 31.5 × 0.5
         = 54.5伤害

结论:
- 爆头暴击提供了最高伤害（110），但触发率低（11.25%）
- 爆头普通是主要伤害来源（73.1），触发率高（88.75%）
- 暴击抗性将暴击触发率降低了一半（22.5% → 11.25%）
- 但爆头基础倍率（2.45）不受影响，依然是核心输出方式
- 护甲穿透提升了约14%的实际伤害
- 暴击倍率从1.2提升到1.5，期望伤害提升约6.5%
```

### 6.4 Boss战设计

#### Boss战设计原则

**阶段式设计**:
```
第一阶段（100%-70% HP）:
- 基础攻击模式
- 2-3个技能
- 较慢攻击频率

第二阶段（70%-40% HP）:
- 解锁新技能
- 攻击频率提升
- 召唤小怪

第三阶段（40%-0% HP）:
- 狂暴状态
- 所有技能
- 攻击频率最高
- 大量小怪
```

**弱点机制**:
```
时间弱点:
- Boss使用特定技能时出现弱点
- 攻击弱点造成3倍伤害
- 弱点持续3-5秒

部位破坏:
- 攻击特定部位（如护甲）
- 破坏后该部位受伤×2
- 视觉反馈（护甲破碎）
```

**环境利用**:
```
环境武器:
- 场地内的特殊武器（如重机枪）
- 造成大量伤害但有CD
- 例如：固定炮台，每次500伤害，CD 30秒

环境陷阱:
- 吊灯/吊桶（射击后掉落，造成范围伤害）
- 高压电（引Boss踩到，眩晕3秒）
- 爆炸桶（连锁爆炸，大量伤害）
```

## 第九章：消耗品系统

### 9.1 消耗品概述

**设计理念**:
```
参考L4D2: 简洁直接
槽位: 2个（4键医疗，5键投掷）
规则: 每个槽位只能持有1个消耗品
拾取: 即捡即装备，自动替换同类道具
副本规则: 副本内拾取，副本结束清空
```

**消耗品特点**:
```
临时性: 副本结束清空，不保存
策略性: 选择带什么（互斥）
即时性: 拾取即可用，无需制作
```

### 9.4 消耗品拾取规则

**拾取机制**:
```
交互: 靠近后按E键拾取
自动替换: 拾取新的会丢弃旧的（同槽位）
掉落旧的: 丢弃的消耗品掉落在地上（其他玩家可捡）
无库存: 不能携带多个，只能持有1个/槽位
```

**拾取提示**:
```
屏幕中央:
"[E] 拾取 医疗包"

拾取后:
"获得 医疗包"（右上角通知）
"丢弃 止痛药"（如果之前有）

槽位UI更新:
5键图标: 止痛药 → 医疗包
```

**拾取策略选择**:
```
示例情境:
- 当前持有: 止痛药（30%回复）
- 地上: 医疗包（50%回复）
- 当前血量: 80%

选择:
A. 不拾取（保留止痛药，因为血量还够）
B. 拾取（换成医疗包，为后续准备）

游戏不会自动替换，玩家自主决定
```

**掉落显示**:
```
视觉:
- 地上显示消耗品模型
- 发光轮廓（医疗=绿色，投掷=橙色）
- 名称标签（悬浮显示）
- 拾取范围提示（2米内显示[E]）

稀有度颜色:
- 常见: 白色光
- 普通: 绿色光
- 稀有: 蓝色光
- 极稀有: 紫色光
```

### 9.5 消耗品副本规空规则

**副本内规则**:
```
拾取: 副本内随时可拾取
使用: 随时可用（冷却=0）
死亡: 死亡后消耗品不掉落（消失）
复活: 复活后消耗品槽位清空
```

**副本结束规则**:
```
结算时:
- 所有消耗品清空
- 不保存到Hub
- 不可带入下一副本

UI提示:
"副本结束，消耗品已清空"

设计理由:
- 每次副本是独立挑战
- 避免囤积消耗品降低难度
- 参考L4D2设计
```

**检查点规则**:
```
到达检查点时:
- 消耗品不重置
- 继续保留当前持有的
- 死亡重生时才清空

设计理由:
- 检查点是存档点，不是刷新点
- 避免玩家依赖检查点刷消耗品
```

## 第十二章：总结与展望

### 12.1 设计文档总结

**核心设计理念**:
```
1. 射击占80%，技能占20%
2. 合作是锦上添花，不是雪中送炭
3. 双主角差异化明显
4. 简洁的消耗品系统（参考L4D2）
5. 随机事件增加重玩性
```

**核心卖点**:
```
1. 双主角剧情驱动（30万字世界观）
2. 丰富的RPG成长（属性/技能/装备）
3. 随机事件系统（10种事件）
4. 传说武器（5把特殊机制）
5. 本地/在线合作（最多4人）
6. 噩梦难度词缀（10种挑战）
```

**游戏规模**:
```
游戏时长: 15-20小时（主线）
章节数量: 12章
武器数量: 17把（普通）+ 5把（传说）
敌人类型: 7种基础 + Boss变种
技能数量: 男主7个 + 女主7个
被动数量: 4通用 + 2专属/角色
```

**目标玩家**:
```
主要: L4D2/B4B老玩家
次要: 喜欢合作射击的玩家
潜在: 喜欢剧情的玩家
女性玩家: 双主角设计，女性友好
```

```
+ 更简洁（B4B卡牌过于复杂）
```

```
+ 双主角（Darktide 5职业）
```

### 12.5 成功关键因素
