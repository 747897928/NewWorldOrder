## 一、核心游戏框架

### 1.1 游戏类型与定位

**游戏类型**：第三人称合作生存射击游戏（丧尸题材）

**核心玩法**：

- 双主角（陈浩宇/沈芸皖）合作
- 策略射击 + 资源管理 + 剧情选择
- 强调战术配合与角色互补

**游戏模式**：

模式1：单人模式（1个玩家）
├─ 控制1个角色（男主或女主）
├─ 可以切换角色（特定条件，类似刺客信条枭雄）
├─ AI接管另一个角色（跟随，基础战斗）
└─ 平衡：敌人数量-20%

模式2：本地分屏（2个玩家）
├─ 玩家A控制男主，玩家B控制女主
├─ 竖直分屏
└─ 平衡：敌人数量100%（原始难度）

模式3：在线合作（最多4个玩家）
├─ 类似本地分屏，但通过网络
├─ Listen Server
└─ 平衡：敌人数量100%

**游戏规模**：

- 通关时长：≥8小时
- 章节数量：10-15章
- 章节结构：线性副本制（每章30-60分钟）

**目标体验**：为情侣、朋友等提供需要配合的PVE体验，兼顾策略与成长，营造末世求生的紧张感。

### 1.2 Hub系统（安全营地）

**功能区划分**：

1. **公告板**：查看可用任务、势力动态、通缉信息
2. **研究桌**：升级武器、制作消耗品、查看收集品
3. **训练场**：测试武器、练习射击、重置技能点
4. **衣柜**：更换服装外观（无数值影响，纯装饰）
5. **篝火**：触发剧情对话、队友互动、查看日志

**成长系统**：

- **属性加点**：体力、力量、敏捷、感知
- **技能树**：双主角各自独立的技能树（陈浩宇偏输出/破坏，沈芸皖偏治疗/辅助）
- **技能槽配置**：4个技能槽位，战前配置，副本内不可更换

**存档规则**：

- **永久存档**：等级、技能点、核心武器、剧情收集品、势力关系值
- **临时存档**：弹药、临时武器、消耗品（副本结束后清空或部分保留）

### 1.3 战斗机制

#### 1.3.1 角色定位

**男主（陈浩宇）**：

- **角色定位**：前排输出、破坏、吸引仇恨
- **核心技能方向**：爆破专精、战术标记、火力压制
- **终极技能方向**：狂怒模式（短时间火力爆发）

**女主（沈芸皖）**：

- **角色定位**：后排支援、治疗、侦查、控制
- **核心技能方向**：治疗光环、侦查无人机、状态增益
- **终极技能方向**：复苏（复活/无敌）

**【注】**：具体技能数值和机制由开发者根据平衡性单独设计。

#### 1.3.2 弹药与武器系统

**弹药分类（简化版）**：

1. **轻型弹药**：手枪、冲锋枪（常见，伤害低，适合清理游荡者）
2. **步枪弹药**：突击步枪、狙击枪（中等稀有，伤害中等，适合猎手）
3. **霰弹**：散弹枪、破门枪（稀有，近距离高伤，适合吞噬者）
4. **特种弹药**：火箭筒、榴弹发射器（极稀有，范围高伤，适合尸王/Boss）

**核心武器库**：

- 存储在Hub，可带入副本
- 包括：玩家升级的主武器、传说武器、特殊改装枪械

**临时武器**：

- 副本内拾取，结束后消失
- 通常是高性能但弹药有限的特殊武器（如：带榴弹发射器的突击步枪、反器材狙击枪）

#### 1.3.3 单人模式平衡

**AI队友系统**：

- **基础指令**：跟随、防守（守点）、进攻（主动清理）

- 自动行为

  ：

  - 自动治疗/弹药补给
  - 不会抢夺玩家拾取物

- **智能限制**：AI不会使用复杂技能组合，不会主动触发剧情选择

**难度自适应**：

- 单人模式：敌人数量-20%，血量-10%
- 双人模式：原始难度

## 十二、技术约束与开发方案

### 12.1 开发者能力

#### 12.1.1 技术栈

**后端**：Java（服务器架构、数据管理）

**引擎**：Unreal Engine 5

**蓝图/C++**：混合开发（蓝图快速原型，C++优化性能）

**网络**：Steam P2P（点对点联机，降低服务器成本）

#### 12.1.2 已掌握系统

- **GAS（Gameplay Ability System）**：技能系统
- **Mutable**：程序化换装系统
- **基础AI**：行为树、EQS（环境查询系统）

#### 12.1.3 美术资源获取

- **角色**：Daz Studio生成基础模型 → CC5（Character Creator）细化 → UE优化
- **动作**：Mixamo动作库 → 手动调整混合
- **场景/道具**：UE商城资产 + 自建关键资产
- **特效**：Niagara粒子系统

#### 12.1.4 开发约束

- **低成本**：独立开发或小团队（1-3人）
- **小规模**：非开放世界，线性副本制
- **资产复用**：同一场景/敌人类型多次使用（通过剧情合理化）

------

### 12.2 游戏规模控制

#### 12.2.1 章节制设计

**优点**：

- 避免开放世界的巨大开发成本
- 可逐章发布（早期测试+资金回笼）
- 线性叙事更容易讲好故事

**每章规模**：

- 游戏时长：30-60分钟
- 场景数：2-4个主要场景
- 敌人遭遇：5-8次战斗
- 剧情节点：3-5个关键对话/选择

#### 12.2.2 线性副本设计

**固定地图大小**：每个副本约0.5-1km²

**可重复游玩**：

- 不同难度（简单/普通/困难/噩梦）
- 挑战模式（限时、无补给、仅近战等）
- 收集品（一周目可能错过的日记/武器配件）

#### 12.2.3 资源管理机制

**副本内**：

- 弹药紧张（鼓励节约、精准射击）
- 补给点有限（迫使玩家做取舍）
- 临时武器强力但结束后消失（体验多样武器，但不破坏平衡）

**Hub内**：

- 资源充足（玩家可以放松）
- 自由配置装备
- 升级技能（RPG成长感）

#### 12.2.4 成长节奏

**前期（第1-5章）**：

- 功能性技能为主（如"快速换弹"、"治疗光环"、"狂怒模式"）
- 武器种类逐渐解锁
- 敌人类型逐渐增多（游荡者→猎手→吞噬者）

**中期（第6-10章）**：

- 数值化提升（攻击力+20%、暴击率+30%、暴击伤害+20%）
- 传说武器开始出现
- 敌人机制复杂化（需要配合克制）

**后期（第11-15章）**：

- 终极技能（如"陈浩宇的狂怒"、"沈芸皖的复苏"）
- 多结局分支
- 觉醒者、尸王级敌人

#### 12.2.5 避免快速碾压

**敌人随玩家等级缩放**：

- 基础数值跟随玩家等级提升
- 但机制不变（玩家仍需策略）

**高难度挑战**：

- 噩梦难度：敌人数量翻倍，智商提升，玩家血量减半
- 无尽模式：看能坚持多少波尸潮

**成就系统**：

- 鼓励玩家尝试各种玩法（如"仅用手枪通关"、"零伤害通关"）
