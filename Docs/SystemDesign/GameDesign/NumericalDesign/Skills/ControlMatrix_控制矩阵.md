## 控制系统设计理念

控制效果按敌人类型递减，防止无脑控制Boss，保持战术挑战性。

核心原则：
- 普通敌人：吃满控制，鼓励使用控制技能
- 特殊敌人：控制时长减半，仍有明显效果
- 精英敌人：仅打断动作+短时硬直，无法长时控制
- Boss：仅打断动作，不进控制状态

## 敌人分级规则

普通（Common）：
- 特征：基础血量<200，无特殊能力，数量多
- 威胁度：低
- 控制效果：吃满
- 标记猎手被动：不触发回血

包含敌人：
- 游荡者（Wanderer）：150HP，基础近战丧尸
- 爬行者（Crawler）：100HP，地面快速移动
- 潜行者（Stalker）：80HP，隐身突袭

---

特殊（Special）：
- 特征：基础血量100-200，有特殊能力，中等数量
- 威胁度：中
- 控制效果：时长减半或0.5秒硬直
- 标记猎手被动：触发回血12% MaxHP

包含敌人：
- 猎手（Hunter）：120HP，跳跃突袭，高机动
- 缠绕者（Binder）：120HP，束缚技能，限制移动
- 干扰者（Jammer）：100HP，屏蔽雷达，降低视野

---

精英（Elite）：
- 特征：基础血量>400，强力威胁，少量出现
- 威胁度：高
- 控制效果：仅打断动作+0.25-0.5秒硬直
- 标记猎手被动：触发回血12% MaxHP

包含敌人：
- 吞噬者（Devourer）：600HP，高伤害，吞噬攻击
- 重装士兵（Juggernaut）：350HP，高护甲，压制火力

---

首领（Boss）：
- 特征：血量800-3000，机制战，单独设计
- 威胁度：极高
- 控制效果：仅打断动作，不进控制状态
- 标记猎手被动：触发回血12% MaxHP

包含敌人：
- Chapter 5 Boss：变异巨兽（1500HP）
- Chapter 10 Boss：最终形态（3000HP）

## 控制类型与效果

### 眩晕 Stun

来源：
- 震撼手雷（男主）
- 无人机死亡爆炸（女主）

效果：
- 普通敌人：3秒眩晕，无法移动/攻击
- 特殊敌人：1.5秒眩晕 或 0.5秒硬直
- 精英敌人：0.3秒硬直，打断动作
- Boss：仅打断动作，不眩晕

实战数值：
- 震撼手雷：普通敌人眩晕3秒（2秒基础）
- 无人机爆炸：普通敌人眩晕2秒

设计意图：
- 短时控制，适合爆发输出
- 特殊敌人减半，仍有效
- 精英/Boss仅打断，需要技巧

---

### 冻结 Freeze

来源：
- 冰冻武器（未实现）
- 冰冻陷阱（未实现）

效果：
- 普通敌人：3秒冻结，无法移动，受伤+30%
- 特殊敌人：1.5秒冻结 或 0.5秒硬直，受伤+15%
- 精英敌人：0.5秒硬直，受伤+10%
- Boss：仅打断动作，无加成

实战数值：
- 3秒冻结期间，伤害+30%
- 配合爆发技能快速击杀

设计意图：
- 长时控制+易伤，强力控制手段
- 当前未实现，预留机制

---

### 麻痹 Paralyze

来源：
- 电击武器（未实现）
- 麻痹陷阱（未实现）

效果：
- 普通敌人：2秒麻痹，攻击速度-50%
- 特殊敌人：1秒麻痹 或 0.5秒硬直
- 精英敌人：0.25秒硬直
- Boss：仅打断动作

实战数值：
- 2秒麻痹期间，攻击速度减半
- 适合拉开距离

设计意图：
- 中等控制，降低攻击威胁
- 当前未实现，预留机制

---

### 减速 Slow

来源：
- 感染抑制剂（女主）
- 冰冻武器辅助效果（未实现）

效果：
- 普通敌人：移速-40%
- 特殊敌人：移速-20%
- 精英敌人：移速-10%
- Boss：移速-5%

实战数值：
- 感染抑制剂：10秒持续，移速-40%
- 离开范围后持续3秒（普通敌人）

设计意图：
- 轻度控制，不完全限制行动
- 对所有敌人有效，包括Boss
- 适合风筝战术

---

### 硬直 Hitstun

来源：
- 所有控制技能对精英/Boss的降级效果
- 打断敌人动作

效果：
- 打断当前动作（攻击/技能）
- 短时硬直（0.25-0.5秒）
- 无法移动或攻击

实战数值：
- 震撼手雷对精英：0.3秒硬直
- 破甲射击对Boss：打断充能攻击

设计意图：
- 保证控制技能对精英/Boss仍有价值
- 打断机制提供战术时机
- 硬直时间短，需要精准把握

## 控制免疫与抵抗

控制免疫（Boss特性）：
- 部分Boss阶段免疫所有控制
- 仅在特定阶段可被打断
- 例如：Chapter 10 Boss狂暴状态免疫控制

控制抵抗（精英特性）：
- 精英敌人控制抵抗+80%
- 控制时长×0.2（3秒→0.6秒）
- 或直接降级为硬直

连续控制递减：
- 同一敌人10秒内受到第二次控制，时长-50%
- 第三次控制，时长-75%
- 防止无限控制循环

## 实战示例

男主震撼手雷：
- 投向普通敌人群：3秒眩晕，击杀时间窗口
- 投向特殊敌人（猎手）：1.5秒眩晕，打断跳跃
- 投向精英敌人（吞噬者）：0.3秒硬直，打断吞噬动作
- 投向Boss：打断充能攻击，创造输出窗口

女主感染抑制剂：
- 范围内普通敌人：移速-40%，几乎静止
- 范围内特殊敌人：移速-20%，仍可缓慢接近
- 范围内精英敌人：移速-10%，轻微影响
- 范围内Boss：移速-5%，几乎无影响

控制组合：
- 震撼手雷+感染抑制剂：眩晕3秒+离开后减速3秒=总计6秒控制
- 配合易伤效果：震撼+30%+标记+25%=1.625倍伤害
- 爆发窗口：6秒内击杀普通敌人

## 控制技巧

打断Boss技能：
- 观察Boss充能动作
- 使用震撼手雷打断

- 使用感染抑制剂减速

控制时机把握：
- Boss充能时打断
- 精英攻击前硬直
- 普通敌人聚集时AOE控制

## 控制效果实现要点

GameplayTag标记：
- Status.Stunned：眩晕状态
- Status.Frozen：冻结状态
- Status.Paralyzed：麻痹状态
- Status.Slowed：减速状态
- Status.Hitstun：硬直状态

控制时长计算：
```cpp
float CalculateControlDuration(EEnemyTier Tier, float BaseDuration, EControlType Type)
{
    switch(Tier)
    {
        case EEnemyTier::Common:
            return BaseDuration; // 100%
        case EEnemyTier::Special:
            return BaseDuration * 0.5f; // 50%或硬直
        case EEnemyTier::Elite:
            return 0.3f; // 固定硬直
        case EEnemyTier::Boss:
            return 0.0f; // 仅打断，不施加控制
    }
}
```

连续控制递减：
```cpp
float ApplyDiminishingReturns(float Duration, int32 RecentControlCount)
{
    if (RecentControlCount == 1) return Duration * 0.5f; // -50%
    if (RecentControlCount >= 2) return Duration * 0.25f; // -75%
    return Duration;
}
```

打断机制：
- 监听敌人当前动画状态
- 控制技能命中时，强制打断动画
- 重置敌人行为树到Idle状态
